> 最后更新: 2026-03-20
> 维护者: CodeBuddy（每次改 UI/交互/流程后同步更新）
> 用途: 验收对照基准 + Codex 理解"正确行为"的参考

## 体验总览（时间线）

```
玩家加入
  │ 自动分配队伍(红/蓝)，默认选后羿，传送到出生点
  ▼
[Waiting] 几乎瞬间跳过（当前 MinPlayers=1，调试模式）
  ▼
[HeroSelect 30秒] 左上角弹出英雄选择面板
  ▼
[Countdown 5秒] 面板关闭，倒计时
  ▼
[InProgress 最长600秒] 正式对战
  │  移动 / 技能 / 普攻 / 死亡重生 / 泉水回血
  ▼
[Ended 10秒] 广播胜方（⚠️ 无结算UI）→ 自动重置 → 循环
```

## 阶段 1: 进入游戏 → Waiting

### 玩家看到什么
- 一张 **200×300 studs** 的纵向对称竞技场
- 四周被 **12 高半透明混凝土边界墙** 围住
- 地面是草地材质（RGB 85,120,70）

### 地图布局（从蓝方到红方）

| 区域 | 位置 | 描述 |
|------|------|------|
| 蓝方泉水 | Z=-140 | 16×16 半透明蓝色 Neon 方块，带粒子发光，回血 100HP/s + 回蓝 50MP/s |
| 蓝方出生点 | Z=-135 | 8×8 蓝色 Neon 平台 |
| 蓝方基地 | Z=-130 | 30×30 平台 + 6×10 发光核心（5000HP），头顶显示血条 |
| 蓝方掩体 | Z=-20~-65 | 5 面灰色混凝土墙壁 + 装饰石柱 |
| 中心战斗区 | Z=0 | 60×60 浅灰色混凝土地面 + 白色半透明中线 |
| 训练假人(×3) | Z=-15~-20 | R6 人形模型，5000HP，头顶显示 DPS 统计面板 |
| 红方掩体 | Z=+20~+65 | 蓝方镜像对称 |
| 红方基地 | Z=+130 | 同蓝方，红色 |
| 红方出生点 | Z=+135 | 红色 8×8 Neon 平台 |
| 红方泉水 | Z=+140 | 同蓝方，红色 |

掩体总数: 14 个（7 组 × 对称 2）

### 服务端行为
- 玩家加入 → `TeamManager.assignPlayer()` 分队
- 默认选择后羿 → `HeroManager.selectHero(player, "houyi")`
- 加载角色 → 传送到出生点
- MinPlayers=1 时 0.5 秒后自动进入 HeroSelect

### 客户端行为
- 无专门等待 UI，玩家已可看到地图、控制角色移动
- 英雄选择面板默认隐藏

## 阶段 2: HeroSelect（30 秒）

### 玩家看到什么
- **左上角**自动弹出英雄选择面板
- 面板标题："切换英雄（点击立即切换）"
- 深色半透明背景（RGB 20,20,30），圆角

### 英雄卡片
水平滚动排列，每张卡片包含：
- 顶部 3px 职业色条（射手=金色，坦克=蓝色，法师=紫色）
- 圆形头像框（50×50，英雄名首字 + 身体颜色代替图标）
- 英雄名称 + 职业标签
- 属性面板（HP/MP/ATK/AP/DEF/MR，10 号字）
- 技能列表（[Q]/[W]/[E]/[R] + 技能名，9 号字）

### 可选英雄

| 英雄 | 职业 | HP | MP | ATK | AP | 移速 |
|------|------|-----|-----|-----|-----|------|
| 后羿 | 射手 | 1000 | 500 | 50 | 0 | 20 |
| 廉颇 | 坦克 | 1800 | 300 | 80 | 0 | 16 |
| 安琪拉 | 法师 | 800 | 600 | 30 | 80 | 18 |

### 交互
- 点击卡片 → 立即切换英雄
- 不选 → 保持默认后羿
- 30 秒到期 → 自动进入 Countdown

## 阶段 3: Countdown（5 秒）

### 玩家看到什么
- 英雄选择面板关闭
- 服务端每秒广播一次 `{state="Countdown", countdown=N}`
- ⚠️ **客户端没有倒计时数字 UI**——仅在控制台打印

### 服务端行为
- 倒计时结束 → 调用 `_startGame()` → 进入 InProgress

## 阶段 4: InProgress（对战）

### 4.1 移动

**PC 端:**
- **右键单击**地面 → 角色朝目标点移动
- **右键长按** → 持续更新目标点
- 到达目标 1.5 studs 范围内自动停止
- 地面显示**绿色圆柱指示器**（Neon 材质，RGB 80,255,120），0.6 秒渐隐

**移动端:**
- 点击地面 → 移动
- 屏幕底部 160px 范围内的点击不触发移动（HUD 死区保护）

**通用:**
- WASD 被三重禁用，不可用于移动
- 角色 AutoRotate=false，朝向由移动方向控制

### 4.2 技能释放

**按键:** Q / W / E / R

**流程:**
1. 按技能键 → 检查是否被动（被动则忽略）
2. 检查 CD（剩余 > 0.2s 则忽略，≤ 0.2s 进入预输入）
3. 根据施法类型分流：
   - **Instant（瞬发）**: 直接释放
   - **Direction / Position / Channel**: 显示指示器 → 等待确认

**预输入:** CD 最后 0.2s 内按键 → 缓存 → CD 结束瞬间自动释放

**指示器交互:**
- **左键单击** → 确认释放
- **再按同一技能键** → 确认释放
- **ESC** → 取消
- **按另一个技能键** → 切换到新技能指示器
- 指示器实时跟随鼠标方向，每帧更新

**施法时:** 只有真正发包时才停止移动（避免"顿一下"的手感问题）

### 4.3 技能指示器类型

| 类型 | 说明 |
|------|------|
| Arrow（箭头） | 从角色延伸的矩形条 + 可选箭头头部 |
| Circle（圆形 AOE） | 鼠标位置的圆圈，可含内圈 |
| Fan（扇形） | 角色前方扇形区域 |
| Rectangle（矩形） | 方向性矩形区域 + 边框 |
| SelfCircle（自身圆形） | 以角色为中心的圆圈 |

所有指示器有射程限制（maxRange），位置型技能预览和实际落点统一裁剪。

### 4.4 普通攻击

- **左键单击**（无指示器激活时）→ 朝鼠标方向普攻
- 基础间隔 1.0 秒
- 释放时自动停止移动

### 4.5 视角控制

- **固定 55° 俯视角**（LOL 风格），摄像机完全手动控制
- 鼠标光标始终可见且自由移动
- **滚轮缩放**: 20~70 studs，每次变化 5
- **屏幕边缘滚屏**: 鼠标靠近边缘 20px 内触发，速度 40 studs/秒，最大偏移 60
- **空格键**: 镜头平滑回中到角色位置
- **角色重生时**: 自动重置镜头偏移

### 4.6 UI 元素

#### 技能栏（底部居中）
- 4 个技能槽，每个 70×70 像素，间距 10
- 每个槽显示: 类型图标 + 技能名 + 蓝耗 + 按键提示(Q/W/E/R)
- CD 中: 黑色半透明遮罩从下往上覆盖 + 倒计时数字
- 类型颜色: 绿=瞬发, 蓝=方向, 橙=范围, 紫=持续, 灰=被动
- 移动端点击技能栏也可触发技能（透明扩大点击区）
- 廉颇专属: 技能栏上方显示**战意条**（橙→红渐变进度条）

#### 血蓝条 HUD（底部居中偏上）
- 250×50 像素，半透明深色背景
- 上方: HP 条（绿→黄→红渐变）+ 数字
- 下方: MP 条（蓝色）+ 数字

#### 头顶血条
- 所有**其他玩家**头顶显示名字 + 血条（自己用 HUD 代替）
- 友军: 名字绿色，血条绿→黄→红
- 敌军: 名字红色，血条固定红色系

#### 战斗信息
- **浮动伤害数字**: 从受击位置向上飘 1 秒渐隐
  - 物理=金色(255,200,100) / 法术=紫色(180,100,255) / 真实=白色
- **击杀播报**: 屏幕右上角，"XXX 击杀了 YYY"，5 秒后淡出
- **施法进度条**: 屏幕中央偏下，紫→金渐变 + 倒计时（引导施法时显示）

#### 英雄切换面板
- 左上角折叠按钮始终可见
- ⚠️ **已知 Bug**: 游戏中展开面板点击切换英雄无效（BUG-001）

### 4.7 泉水回血
- 站在己方泉水区域 → 每秒回 100HP + 50MP
- 泉水有粒子发光特效

### 4.8 训练假人
- 3 个假人位于地图中部偏蓝方
- 5000HP，可被攻击
- 头顶 DPS 统计面板实时显示输出数据

## 阶段 5: 死亡与重生

### 死亡时
- **服务端**: 清理状态效果 + 战意数据，计算复活时间
- 复活时间: `min(15, 5 + (死亡次数-1))` 秒（首次 5 秒，递增 1 秒/次，上限 15 秒）

### 客户端表现
- **全屏半透明黑色遮罩**
- 居中白色大字（36 号）: "复活倒计时: X.X"
- 每 0.1 秒更新倒数
- 倒计时结束显示 "复活中..."

### 重生
- 传送到己方出生点（±3 studs 随机偏移）
- 回满血蓝
- 摄像机偏移重置
- 隐藏复活遮罩

---

## 阶段 6: Ended（10 秒）

### 触发条件

| 条件 | 说明 |
|------|------|
| 击杀达标 | 某队击杀数 ≥ 20（TotalKills 模式） |
| 超时 | 600 秒到期，比较双方击杀数 |
| 所有玩家离开 | 玩家数 ≤ 0 → winner="None" |

⚠️ **已知缺陷**: 默认配置 `VictoryCondition="BaseDestroy"`，但代码中**只实现了 TotalKills 检查**。基地有 5000HP 和 Humanoid，但没有监听基地死亡事件来触发结束。

### 结束时
- 广播: `{state="Ended", winner="Red"/"Blue"/"None", redKills=N, blueKills=N}`
- ⚠️ **无结算 UI** — 客户端仅在控制台打印结果
- 英雄选择面板关闭

### 重置
- 10 秒后自动重置 → 回到 Waiting
- 人数达标（≥1）则 3 秒后重新进入 HeroSelect

## 已知体验缺陷

| 缺陷 | 现状 | 对应看板 |
|------|------|---------|
| 游戏中切换英雄无效 | HeroSwitch 被 `if false` 禁用 | BUG-001 |
| Remote 失败白屏 | getRemotes() 失败 → error() 硬崩 | BUG-002 |
| VFX 可能静默加载失败 | FindFirstChild 时序风险 | BUG-003 |
| 无倒计时 UI | Countdown 阶段只在控制台打印 | 未建卡 |
| 无结算画面 | Ended 阶段无 UI，只在控制台打印 | 未建卡 |
| 基地摧毁胜利未实现 | 配置写的 BaseDestroy 但代码只检查 TotalKills | 未建卡 |
