**PassiveConfig.lua 要求**:

- Mana: BaseMax=500, GrowthPerLevel=40, RegenPerSecond=5, BarColor=蓝

- None: BaseMax=0, ShowBar=false

### T2: PassiveSystem 运行时

| 属性 | 值 |
|------|-----|
| 优先级 | P0 — 被动核心逻辑 |
| 预估行数 | ~200 行 |
| 前置依赖 | T1 (PassiveConfig) |

**新增文件**:

| 文件 | 位置 | 类型 |
|------|------|------|
| `PassiveSystem.lua` | `src/ServerScriptService/ServerModules/PassiveSystem.lua` | ModuleScript |

**API 要求**:
```lua
PassiveSystem:RegisterPassives(player, heroId)   -- 注册英雄被动
PassiveSystem:UnregisterPassives(player)          -- 注销所有被动
PassiveSystem:OnEvent(eventType, player, context) -- 事件派发入口
PassiveSystem:IsPassiveOnCooldown(player, passiveId) -- CD查询
```

**核心逻辑**:
1. RegisterPassives: 从 HeroConfig 读取 Passives 列表 → 从 PassiveConfig 加载被动定义 → 存入 `activePassives[player]`
2. OnEvent: 遍历玩家已注册被动 → 匹配 TriggerEvent → 检查 Conditions → 通过则调用 `BuffSystem:ApplyEffect()`
3. 后羿叠层: Stack 模式，每次 OnHit 叠加一层 Effect 3080，最多 5 层。3秒无命中后 Heartbeat 检测并衰减（每秒移除1层）
4. 廉颇 CD: OnDamaged 时检查内置 CD (8s)，通过则 ApplyEffect(3081) 并 ApplyEffect(3082)，更新 CD
5. 死亡暂停: 检测 Humanoid.Health <= 0 → 暂停所有被动触发，复活后恢复

**依赖模块**: `BuffSystem`, `PassiveConfig`, `HeroRegistry`

**验收标准**: AC-B02, AC-B03, AC-B04, AC-E02, AC-X01

### T3: EnergySystem 运行时

| 属性 | 值 |
|------|-----|
| 优先级 | P0 — 能量核心逻辑 |
| 预估行数 | ~150 行 |
| 前置依赖 | T1 (EnergyConfig) |

**新增文件**:

| 文件 | 位置 | 类型 |
|------|------|------|
| `EnergySystem.lua` | `src/ServerScriptService/ServerModules/EnergySystem.lua` | ModuleScript |

**API 要求**:
```lua
EnergySystem:InitEnergy(player, heroId)      -- 初始化能量
EnergySystem:CanCast(player, cost)            -- 检查能否施法
EnergySystem:ConsumeEnergy(player, amount)    -- 扣除能量
EnergySystem:AddEnergy(player, amount, reason)-- 增加能量（Rage用）
EnergySystem:GetEnergy(player)                -- 查询当前能量
EnergySystem:RemovePlayer(player)             -- 清理
```

**核心逻辑**:
1. InitEnergy: 读取 HeroConfig.EnergyType → EnergyConfig 获取参数 → 初始化 `energyStates[player]`
   - Mana/Energy: current = BaseMax（满值开局）
   - Rage: current = 0（空怒开局）
   - None: 不初始化
2. Heartbeat tick:
   - Mana/Energy: current += RegenPerSecond * dt, clamp(0, max)
   - Rage: 脱战检测(now - lastCombatTime > DecayDelay) → 衰减 DecayRate * dt
3. SyncEnergyEvent: 0.5s 间隔 OR 变化 > 5% 立即同步 → FireClient({current, max, energyType})
4. 死亡处理: Rage 重置为 0，Mana/Energy 保持当前值
5. 等级提升: Mana 的 max += GrowthPerLevel，current += GrowthPerLevel

**依赖模块**: `EnergyConfig`, `HeroRegistry`, `SyncEnergyEvent` (RemoteEvent)

**验收标准**: AC-C02, AC-C03, AC-C04, AC-E03, AC-E04, AC-X02

### T7: PlayerSkillManager 集成（能量检查 + 被动注册）

| 属性 | 值 |
|------|-----|
| 优先级 | P0 — 核心集成点 |
| 预估行数 | ~30 行改动 |
| 前置依赖 | T2 (PassiveSystem), T3 (EnergySystem) |

**修改文件**:

| 文件 | 改动 |
|------|------|
| `src/ServerScriptService/PlayerSkillManager.server.lua` | 3 处修改 |

**修改点**:

1. **顶部 require 新增**:
   ```lua
   local PassiveSystem = require(ServerModules.PassiveSystem)
   local EnergySystem = require(ServerModules.EnergySystem)
   ```

2. **CastSkillEvent 处理中，在 `skillInstance:CanCast()` 之后、`OnCast()` 之前**:
   ```lua
   -- 能量检查
   local energyCost = skillData.EnergyCost or 0
   if energyCost > 0 and not EnergySystem:CanCast(player, energyCost) then
       return -- 能量不足，拒绝施法
   end
   -- ... OnCast() ...
   -- 能量扣除
   if energyCost > 0 then
       EnergySystem:ConsumeEnergy(player, energyCost)
   end
   ```

3. **英雄装备/切换时（HeroSwapEvent 或初始装备逻辑）**:
   ```lua
   PassiveSystem:UnregisterPassives(player) -- 注销旧被动
   PassiveSystem:RegisterPassives(player, heroId) -- 注册新被动
   EnergySystem:InitEnergy(player, heroId)  -- 初始化能量
   ```

**验收标准**: AC-C03, AC-E05

