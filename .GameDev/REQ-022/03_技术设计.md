# REQ-022 技术设计：移动端摇杆方向映射修复

## 问题根因

摇杆输出 2D 屏幕空间向量，`screenToWorldDirection()` 直接映射为 `Vector3(x, 0, -y)` 假设摄像机朝 -Z。但实际摄像机在角色后上方 `(0, +30, +20)` 朝角色看，LookVector 有 XZ 分量。同时 `Humanoid:Move(dir, true)` 的 `relativeToCamera` 对斜视角行为不直观，导致方向完全错误。

## 解决方案

用摄像机 CFrame 的 LookVector 投影到 XZ 平面，构建"屏幕前/右"到"世界前/右"的变换矩阵。`Humanoid:Move` 改为 `false`（世界绝对坐标）。

## 任务清单

### T-1: 重写 screenToWorldDirection（MobileInputManager.lua）

**文件**: `src/StarterPlayer/StarterPlayerScripts/Modules/MobileInputManager.lua`
**位置**: L42-48 `screenToWorldDirection` 函数

**当前代码**:
```lua
local function screenToWorldDirection(screenDir: Vector2): Vector3
    if screenDir.Magnitude < 0.01 then
        return Vector3.zero
    end
    return Vector3.new(screenDir.X, 0, -screenDir.Y).Unit
end
```

**替换为**:
```lua
local function screenToWorldDirection(screenDir: Vector2): Vector3
    if screenDir.Magnitude < 0.01 then
        return Vector3.zero
    end
    local camera = workspace.CurrentCamera
    if not camera then return Vector3.zero end
    -- 摄像机 LookVector 投影到 XZ 平面 → "屏幕上"对应的世界方向
    local camLook = camera.CFrame.LookVector
    local flatForward = Vector3.new(camLook.X, 0, camLook.Z)
    if flatForward.Magnitude < 0.001 then
        flatForward = Vector3.new(0, 0, -1)
    else
        flatForward = flatForward.Unit
    end
    local flatRight = Vector3.new(flatForward.Z, 0, -flatForward.X)
    local worldDir = (flatRight * screenDir.X + flatForward * (-screenDir.Y))
    if worldDir.Magnitude < 0.001 then return Vector3.zero end
    return worldDir.Unit
end
```

### T-2: Move改为世界绝对坐标（MovementManager.lua）

**文件**: `src/StarterPlayer/StarterPlayerScripts/Modules/MovementManager.lua`
**位置**: L34

**当前代码**:
```lua
humanoid:Move(moveDirection, true)
```

**替换为**:
```lua
humanoid:Move(moveDirection, false)
```

**注意**: L36 的 `humanoid:Move(Vector3.zero, true)` 也需要改为 `false` 以保持一致。
