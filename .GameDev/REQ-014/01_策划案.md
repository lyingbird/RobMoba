# REQ-014: Device Emulator 英雄选择确认后界面卡住

## Bug 描述

在 Roblox Studio Device Emulator 中切换到手机模式（如 iPhone 14 Pro），选择英雄后点击"已确认"按钮，按钮文字变为"✅ 已确认"但界面不关闭、无后续反馈，游戏卡在英雄选择面板。

## 环境

- Roblox Studio Device Emulator
- 设备: iPhone 14 Pro
- 触发条件: `UserInputService.TouchEnabled = true` 且 `UserInputService.KeyboardEnabled = false` → `isMobile = true`

## 初步分析

按钮文字已变为"✅ 已确认"（UI_HeroSelect.lua L660），证明 `lockBtn.MouseButton1Click` 回调已触发。问题在 `onHeroConfirmed()` 回调（Client.client.lua L110-195）的移动端初始化路径（L133-176）中出错，导致 `task.delay(0.5, Hide)` 未被调度执行。

## 验收标准

| AC | 描述 |
|----|------|
| AC-01 | Device Emulator 中选择英雄并确认后，英雄选择面板在 0.5s 后正常关闭 |
| AC-02 | 确认后移动端 UI 系统（摇杆、技能按钮）正常初始化并显示 |
| AC-03 | 英雄动画和左下角小面板正常显示 |
| AC-04 | PC 端（isMobile=false）不受影响，原有逻辑不变 |
| AC-05 | DEBUG_FORCE_MOBILE=true 模式下同样正常工作 |
