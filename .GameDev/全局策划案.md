## 一、游戏概述

### 1.1 产品定位
- **游戏名称**: RobMoba
- **平台**: Roblox (Luau)
- **类型**: MOBA 竞技对战
- **参考作品**: 王者荣耀、英雄联盟
- **目标体验**: 3~8 分钟的快节奏 1v1 对决
- **构建工具**: Rojo (文件系统 → Roblox Studio 同步)

### 1.2 核心游戏循环

```
自由大厅(训练场模式) → 选择英雄 → 练习技能/测试连招 →
进入匹配区域 → 匹配成功 → 
3秒倒计时 → 竞技场1v1对决 → 3杀获胜 → 
5秒结算展示 → 返回大厅(训练场)
```

### 1.3 当前版本状态
- **可用英雄**: 4 名（拉克丝、安琪拉、后羿、廉颇）
- **游戏模式**: 自由大厅 + 1v1 匹配对决
- **技能总数**: 15 个主动技能 + 25 种效果
- **装备道具**: 2 件（狂徒铠甲、无尽之刃）
- **符文系统**: 3 个符文（冷却缩减、多重施法、伤害增幅）
- **最大等级**: 18 级

### 3.2 属性计算公式

```
最终属性 = 基础值(Base) + 等级成长(Growth × (Level-1)) + 装备加成(Equipment)
```

- **满级(18级)** 示例: MaxHP = 850 + 92×17 = **2414**, DEF = 28 + 4.2×17 = **99.4**
- MaxHP 变化时 HP 自动补差: `HP += newMaxHP - oldMaxHP`
- MoveSpeed 实时同步到 `Humanoid.WalkSpeed`

### 3.3 伤害公式

```
物理伤害 = ATK × (100 / (100 + DEF))
魔法伤害 = AP × (100 / (100 + MR))
```

> **示例**: ATK=65 攻击 DEF=28 目标 → 65 × (100/128) ≈ **50.8** 伤害

### 3.4 效果系统

**6 种效果类型**:

| 类型 | 说明 | 示例 |
|------|------|------|
| Damage | 即时伤害 (Physical/Magic) | 所有技能伤害 |
| CC | 控制效果 (Stun/Root/Slow/Knockup) | 安琪拉W眩晕, 拉克丝Q定身 |
| Shield | 护盾 (吸收伤害, 有持续时间) | 拉克丝W, 廉颇W |
| DoT | 持续伤害 (每 tick 造成伤害) | 安琪拉W漩涡, 后羿W |
| HoT | 持续治疗 (预留) | — |
| StatMod | 属性修改 (Flat/Percent) | 后羿Q 攻击增强 |

**叠加规则**:
- **Replace**: 新效果替换旧效果
- **Stack**: 层数叠加 (上限 MaxStacks)
- **Refresh**: 刷新持续时间，保留参数
- **Independent**: 独立多实例

**互斥组 (MutexGroup)**:
- `HardCC` 组: 眩晕(Stun) / 击飞(Knockup) 互斥 — 同一时刻只能存在一个硬控效果

## 六、游戏流程

### 6.1 大厅系统
- **出生位置**: Vector3(-197, 62.5, 204)
- **匹配区域**: 圆柱体, 中心(-180, 62, 180), 半径 15 studs, 半透明蓝色 Neon
- **操作流程**: 自由行走 → 英雄选择(UI_HeroSelect) → 进入匹配区域自动排队
- **限制**: 必须选择英雄才能匹配；匹配中/对决中不能切换英雄
- **训练场模式** (REQ-009): 玩家默认以训练场模式进入大厅，左上角显示控制面板(CD开关/HP刷新/训练假人/等级调整/重置位置)。进入匹配时自动恢复正常设置。训练假人支持被所有技能/普攻命中、受击伤害飘字、CC效果（击飞等）(REQ-010修复)。切换CD开关为ON时立刻重置所有正在冷却的技能(REQ-013修复)。

### 6.2 匹配系统
- **匹配条件**: 队列 ≥ 2 人即匹配
- **取消方式**: 离开匹配区域 / 手动取消
- **掉线处理**: 匹配中掉线自动退出队列

### 6.3 对决系统

| 参数 | 值 |
|------|-----|
| 竞技场中心 | Vector3(0, 62, 0) |
| 双方间距 | 80 studs (各距中心 40) |
| 倒计时 | 3 秒 |
| 胜利条件 | 先达 3 杀 |
| 重生时间 | 5 秒 |
| 结算展示 | 5 秒 |
| 阵营 | RedTeam / BlueTeam |

**对决生命周期**:
```
匹配成功 → 通知双方(matched) → 3秒倒计时(countdown) → 
分配阵营 → 传送至竞技场 → 通知开始(start) → 
战斗循环(每0.5s检测击杀) → 一方达3杀 → 
通知结果(result) → 5秒展示 → 清除阵营 → 传送回大厅
```

**掉线处理**: 掉线方自动判负，对方获胜

## 七、操控与表现

### 7.1 输入系统 (InputManager)
- **操控风格**: LOL 风格（右键移动 + 技能键释放）

- **普攻参数**: 射程 10, 间隔 0.8s, 长按阈值 0.3s
