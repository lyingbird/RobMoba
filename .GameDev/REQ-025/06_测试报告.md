## 验收标准测试结果

### AC-001: 小地图上的田字格/网格线不再显示 ✅ PASS

**验证方法**: 源码审查 `UI_Minimap.lua` 第 150-170 行

**证据**:
- `hLine.Visible = false` (第 159 行) — 水平网格线已隐藏
- `vLine.Visible = false` (第 169 行) — 垂直网格线已隐藏
- 元素保留但不渲染，注释标注 "REQ-025: 隐藏"

### AC-002: 训练场UI面板可通过触摸/鼠标拖拽移动到任意位置 ✅ PASS

**验证方法**: 源码审查 `UI_TrainingPanel.lua` 第 416-489 行

**证据**:
- titleBar 拖拽处理器 (第 418-453 行): `InputBegan` 捕获起始位置 → `InputChanged` 计算 delta 应用到 `panelFrame.Position` → `InputEnded` 停止拖拽
- collapsedIcon 拖拽处理器 (第 456-489 行): 同样模式，独立 `do...end` 作用域
- 支持 `Touch` + `MouseButton1`/`MouseMovement` 双输入类型
- 位置 clamp 到 `[0, viewportSize - frameSize]` 防止拖出屏幕

### AC-003: 训练场UI面板的DisplayOrder为最高优先级 ✅ PASS

**验证方法**: 源码审查 `UI_TrainingPanel.lua` 第 110 行 + 全项目 DisplayOrder 对比

**证据**:
- `screenGui.DisplayOrder = 100` (第 110 行)
- 其他 ScreenGui DisplayOrder: HeroMiniPanel=6, 其余默认≤10
- 100 >> 10, 确认为最高优先级

### AC-004: 英雄切换小面板(HeroMiniPanel)位于屏幕右上角 ✅ PASS

**验证方法**: 源码审查 `MobileConfig.lua` 第 168-170 行

**证据**:
- `MobileConfig.MINI_PANEL_POS = { X = 0.83, Y = 0.08 }` — 屏幕右上角 (X=83%, Y=8%)
- 注释标注 "REQ-025: 英雄切换小面板位置参数 — 移至右上角(用户截图指示)"
- X=0.83 对应右侧区域，Y=0.08 对应顶部区域，与用户截图中红色箭头/矩形位置一致

### AC-005: 拖拽交互不与其他UI操作冲突 ✅ PASS

**验证方法**: 架构分析 + 事件绑定审查

**证据**:
- 拖拽仅绑定在 `titleBar.InputBegan` 和 `collapsedIcon.InputBegan`（非面板内部按钮）
- 面板内部功能按钮 (CD/HP/假人/等级/重置) 使用 `MouseButton1Click`，与拖拽事件互不干扰
- 两个拖拽处理器使用独立 `do...end` 块隔离变量作用域
- TrainingPanel 在独立 ScreenGui (DisplayOrder=100) 中，摇杆/技能按钮在其他 ScreenGui，事件不穿透
- collapse 按钮 `closeBtn.MouseButton1Click` 独立于 titleBar 拖拽（子元素事件不冒泡到 InputBegan 拖拽）

### AC-006: 修改不影响PC端UI布局 ✅ PASS

**验证方法**: 代码路径分析

**证据**:
- `UI_Minimap.lua` 网格线隐藏: 全平台生效，但小地图本身仅在移动端初始化
- `UI_TrainingPanel.lua` 拖拽: Touch+Mouse 双支持，PC 端也可拖拽(增强功能,不破坏)
- `MobileConfig.lua` MINI_PANEL_POS: 仅被 `UI_HeroSelect.lua` 的移动端路径引用，PC 端 MiniPanel 使用不同的定位逻辑
