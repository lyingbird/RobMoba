## 一、设计概述

### 设计目标
为训练场模式设计一个**轻量、直观、不干扰核心 HUD** 的控制面板。玩家在大厅中一眼就能看到工具栏，快速上手使用。

### 设计原则
1. **不遮挡战斗信息**: 面板位于左上角，远离底部技能栏和血条
2. **一键操作**: 每个功能最多1次点击完成
3. **状态清晰**: 开关型控件要有明确的 ON/OFF 视觉区分
4. **可收起**: 面板可折叠为小图标，不干扰自由探索

## 三、交互状态定义

### 3.1 控件状态

#### Toggle 开关（技能冷却）

| 状态 | 视觉 | 说明 |
|------|------|------|
| OFF（默认）| 灰色背景 `(80,80,80)`, 白色文字 "OFF" | 正常CD |
| OFF+Hover | 浅灰色 `(110,110,110)` | 鼠标悬停 |
| ON | 绿色背景 `(76,175,80)`, 白色文字 "ON" | 无CD模式 |
| ON+Hover | 深绿色 `(56,155,60)` | 鼠标悬停 |
| Disabled | 深灰色 `(50,50,50)`, 文字 50% 透明 | 未选英雄时 |

#### 普通按钮（回满/生成/清除/出生点）

| 状态 | 视觉 | 说明 |
|------|------|------|
| Default | 深蓝色背景 `(40,60,100)`, 白色文字 | 可点击 |
| Hover | 亮蓝色 `(60,90,140)` | 鼠标悬停 |
| Pressed | 白色闪烁 0.1s → 回到 Default | 点击反馈 |
| Disabled | 深灰色 `(50,50,50)`, 文字 50% 透明 | 未选英雄/不可用时 |

#### 加减按钮（等级调整）

| 状态 | 视觉 | 说明 |
|------|------|------|
| Default | 圆形按钮, 深蓝色 | 可点击 |
| Hover | 亮蓝色高亮 | 鼠标悬停 |
| Pressed | 缩放到 90% → 弹回 | 点击反馈 |
| Disabled (−at Lv1) | 深灰色, 不可点击 | 已达下限 |
| Disabled (+at Lv18) | 深灰色, 不可点击 | 已达上限 |

### 3.2 面板状态

| 状态 | 触发条件 | 视觉 |
|------|---------|------|
| 展开 | 进入大厅 / 点击折叠图标 | 完整面板(200×260) |
| 折叠 | 点击 [−] 按钮 | 小图标(44×44) |
| 隐藏 | 进入匹配/对决 | 完全不可见(Visible=false) |
| 禁用 | 未选择英雄 | 面板可见但所有按钮Disabled, 顶部提示"请先选择英雄" |

## 四、反馈规范

| 操作 | 反馈类型 | 反馈内容 | 持续时间 |
|------|----------|----------|----------|
| 开启无CD | 视觉 | Toggle 切换为绿色 + 面板顶部文字闪烁"⚡无CD模式" | 1.5s |
| 关闭无CD | 视觉 | Toggle 切换为灰色 | 即时 |
| 回满HP/MP | 视觉 | 按钮闪绿色 + 角色头顶绿色"+FULL" | 0.5s |
| 生成假人 | 视觉 | 假人计数+1, 假人出现时有缩放动画(0→100%) | 0.3s |
| 清除假人 | 视觉 | 假人计数归0, 假人消失时有淡出 | 0.3s |
| 等级升级 | 视觉 | 数字跳动(旧→新), 属性面板(如有)闪烁 | 0.3s |
| 回到出生点 | 视觉 | 屏幕白闪(传送效果) → 到达出生点 | 0.5s |
| 未选英雄时点击 | 提示 | 面板顶部红色提示"⚠️ 请先选择英雄" | 2s |

## 五、异常处理

| 异常场景 | 处理方式 | 用户提示 |
|---------|---------|---------|
| 网络延迟 | 按钮点击后立即显示效果（乐观更新），服务端确认 | 无（快速响应） |
| 服务端拒绝 | 回滚UI状态 | 红色提示"操作失败" (1.5s) |
| 假人已满(3/3) | 自动移除最早假人，显示新假人 | 计数保持3/3 |
| 匹配中尝试操作 | 面板已隐藏，不可交互 | — |

## 六、Roblox 实现指引

### 6.1 GUI 层级

```
ScreenGui "TrainingPanel" (DisplayOrder = 5, 高于默认但低于对话框)
├── Frame "Panel" (展开状态)
│   ├── Frame "TitleBar"
│   │   ├── TextLabel "Title" (🏋️ 训练场)
│   │   └── TextButton "CollapseBtn" (−)
│   ├── Frame "Row_Cooldown"
│   │   ├── TextLabel "Label" (技能冷却)
│   │   └── Frame "Toggle"
│   │       ├── TextButton "OnBtn"
│   │       └── TextButton "OffBtn"
│   ├── TextButton "RefreshBtn" (❤️ 回满 HP/MP)
│   ├── Frame "Row_Dummy"
│   │   ├── TextButton "SpawnBtn" (🎯 生成假人)
│   │   └── TextButton "ClearBtn" (🗑 清除全部)

│   │   ├── TextButton "LevelDown" (−)
```
