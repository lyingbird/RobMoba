## 第一章 功能概述

### 1.1 背景与目标

**背景**: 当前 RobMoba 的单人体验为"自由大厅"模式，玩家进入后只能在空旷的大厅中行走并前往匹配区域。缺乏系统性的练习工具，新玩家无法方便地测试英雄技能、练习连招。

**目标**: 将大厅默认模式升级为**训练场模式**，提供完善的练习工具面板，让玩家能：
1. 快速测试英雄技能（无CD限制）
2. 反复练习连招（一键回满生命/蓝量）
3. 在训练假人上验证伤害（可视化伤害数字）
4. 随时切换到匹配模式（走向匹配区域即可）

**设计理念**: 参考王者荣耀训练营的"低门槛、快反馈"设计，在 Roblox 平台上做轻量化适配。

### 1.2 竞品分析

#### 王者荣耀训练营

| 功能 | 说明 | 适合本项目? |
|------|------|:-----------:|
| 关闭技能冷却 | 技能CD归零，可无限释放 | ✅ **核心功能** |
| 无敌模式 | 免疫所有伤害 | ✅ 合并到HP刷新 |
| 等级调整 | 手动升级/重置到1级 | ✅ 方便测试不同等级伤害 |
| 增加金币 | +1000金币按钮 | ❌ 当前装备系统简单，暂不需要 |
| 兵线/野怪刷新 | 刷新各类AI单位 | ❌ 当前无小兵/野怪系统 |
| 暴君/主宰Buff | 一键获得野怪Buff | ❌ 当前无野怪系统 |

#### LOL 练习工具

| 功能 | 说明 | 适合本项目? |
|------|------|:-----------:|
| 刷新CD | 所有技能CD立即归零 | ✅ **核心功能** |
| 回满HP/MP | 一键恢复至满 | ✅ **核心功能** |
| 传送到位置 | 点击地图传送 | ❌ 地图小，不需要 |
| 生成训练假人 | 在指定位置生成静止目标 | ✅ 适合技能测试 |
| 锁定等级 | 设置英雄等级 | ✅ 合并为等级调整 |
| 禁用塔/小兵 | 关闭防御塔和兵线 | ❌ 当前无这些系统 |

#### 适配决策

基于当前项目规模（4英雄、1v1模式、无小兵/野怪），选取以下功能：

| # | 功能 | 优先级 | 来源 |
|---|------|--------|------|
| F1 | 开关技能冷却 | P0 必须 | 用户明确要求 |
| F2 | 刷新生命/蓝量 | P0 必须 | 用户明确要求 |
| F3 | 训练假人（Target Dummy） | P0 必须 | MOBA训练场标配 |
| F4 | 等级调整 | P1 推荐 | 方便测试不同等级伤害 |
| F5 | 重置位置（回到出生点） | P1 推荐 | 方便反复练习 |

### 1.3 设计范围

**做**:
- 训练场控制面板 UI（左上角工具栏）
- 服务端训练场状态管理（TrainingManager）
- 训练假人生成与管理
- 5个控制功能（F1-F5）
- 与现有大厅系统无缝集成

**不做**:
- 金币系统（当前装备简单，直接使用背包系统）
- AI对手（超出M规模）
- 兵线/野怪系统（不存在）
- 录像/回放功能

## 第二章 功能详细设计

### 2.1 训练场进入流程

**玩家默认以训练场模式进入大厅。**

```
玩家加入服务器
  → 传送到大厅出生点 (现有)
  → 自动进入训练场模式 (新增)
  → 显示训练场控制面板 (新增)
  → 在出生点附近生成训练假人 (新增)
  → 玩家自由练习
  
  → [可选] 走向匹配区域 → 控制面板自动隐藏 → 恢复正常模式 → 进入匹配
  → [可选] 匹配取消/对决结束 → 返回大厅 → 重新显示控制面板
```

**状态集成**: 训练场不新增独立状态，复用现有 `LOBBY` 状态。控制面板仅在 `LOBBY` 状态时显示。进入 `MATCHING` 或 `DUELING` 时自动隐藏面板并**恢复正常设置**（CD恢复、无敌关闭等）。

### 2.2 控制面板（Training Panel）

控制面板位于屏幕**左上角**，为一个紧凑的垂直工具栏。

#### 面板布局

```
┌──────────────────────────────────────┐
│  🏋️ 训练场                    [收起] │
├──────────────────────────────────────┤
│  [🔄] 冷却: [ON ▪ OFF]              │  ← F1: 技能CD开关
│  [❤️] 回满HP/MP  [按钮]             │  ← F2: 一键回满
│  [🎯] 假人: [生成] [清除]            │  ← F3: 训练假人
│  [⬆️] 等级: [- ] Lv.1 [ +]          │  ← F4: 等级调整
│  [🏠] 回到出生点  [按钮]             │  ← F5: 重置位置
└──────────────────────────────────────┘
```

#### F1: 开关技能冷却

| 参数 | 值 |
|------|-----|
| 默认状态 | OFF（正常CD） |
| 开启效果 | 所有技能CD立即归零 + 后续技能释放无CD消耗 |
| 关闭效果 | 恢复正常CD（当前CD保持，不重置） |
| 蓝量消耗 | 开启无CD时同时**取消蓝量/能量消耗** |
| 同步方式 | C→S: TrainingEvent {action:"toggleCD", enabled:bool} → S→C: SyncCooldownEvent |

**MOBA参考**: 王者荣耀训练营"关闭冷却"按钮，开启后技能CD和蓝耗同时清零。

#### F2: 刷新生命/蓝量

| 参数 | 值 |
|------|-----|
| 触发方式 | 点击按钮 |
| 效果 | HP回满(Humanoid.Health = MaxHealth) + MP回满 + 能量回满 + 清除所有负面Buff |
| 冷却 | 无冷却（可连续点击） |
| 同步方式 | C→S: TrainingEvent {action:"refreshHP"} → 服务端执行回满 |

**MOBA参考**: LOL练习工具"Refill HP and Mana"按钮。

#### F3: 训练假人（Target Dummy）

| 参数 | 值 |
|------|-----|
| 生成方式 | 点击"生成"按钮 |
| 生成位置 | 玩家前方 10 studs |
| 假人属性 | HP=10000, DEF=0, MR=0（纯肉靶，不会死亡） |
| 假人行为 | 静止不动，不攻击，受到攻击后显示伤害数字 |
| 假人外观 | 标准 R15 Dummy 模型，灰色，头顶血条 |
| 最大数量 | 3 个（超过则最早的自动移除） |
| 清除方式 | 点击"清除"按钮移除所有假人 |
| 受击反馈 | 显示浮动伤害数字（红色=物理，紫色=法术） |
| HP重置 | 假人HP每5秒自动回满（不死亡机制：HP降到1时不再扣减） |

**MOBA参考**: LOL训练假人 — 静止目标、0防御、不死亡、显示伤害数字。王者训练营也有类似机制（预设的敌方英雄作为靶子）。

**设计选择**: 采用静止假人而非AI敌人，原因：
1. 开发成本低（M规模内可完成）
2. 更适合纯技能测试场景
3. 避免 AI 行为不一致导致的测试干扰

#### F4: 等级调整

| 参数 | 值 |
|------|-----|
| 触发方式 | 点击 +/- 按钮 |
| 范围 | 1 ~ 18（与现有等级系统一致） |
| 效果 | 立即设置玩家等级，触发属性重算 |
| 同步方式 | C→S: TrainingEvent {action:"setLevel", level:number} → SyncLevelEvent |

**MOBA参考**: 王者训练营"等级调整"功能。

#### F5: 重置位置

| 参数 | 值 |
|------|-----|
| 触发方式 | 点击按钮 |
| 效果 | 玩家传送回大厅出生点 Vector3(-197, 62.5, 204) |
| 附加效果 | 同时执行 F2（回满生命） |

### 2.3 训练假人详细设计

#### 假人创建

```
生成假人
  → 创建 R15 Dummy Model
  → 设置 Humanoid: MaxHealth=10000, Health=10000
  → 添加 BillboardGui 血条
  → 设置 Anchored (不可推动)
  → 注册到 TrainingManager.dummies 列表
```

#### 伤害显示

假人被攻击时，在头顶显示浮动伤害数字：
- 数字从头顶向上飘动 1.5 studs，持续 1 秒后淡出
- 物理伤害 = 红色 (#FF4444)
- 法术伤害 = 紫色 (#AA44FF)
- 回复 = 绿色 (#44FF44)

#### HP回满机制

- 假人不会真正死亡：当 Health ≤ 1 时，锁定 Health = 1
- 每 5 秒检查一次，如果 Health < MaxHealth，则回满
- 或：玩家停止攻击 3 秒后，假人 HP 快速回满

### 2.4 技能重置详细设计

开启无CD模式时：
1. 服务端标记玩家 `noCooldown = true`
2. `BaseSkill:_startCooldown()` 检查此标记，如果为 true 则跳过CD设置
3. 同时标记 `noCost = true`，`BaseSkill:_consumeResources()` 跳过蓝量/能量消耗
4. 客户端 SyncCooldownEvent 不发送（或发送CD=0），UI上技能图标始终可用

### 2.5 状态同步与安全

#### 新增 RemoteEvent

| 事件名 | 方向 | 用途 |
|--------|------|------|
| TrainingEvent | C→S | 训练场控制指令（toggleCD/refreshHP/spawnDummy/clearDummies/setLevel/resetPosition） |
| TrainingSyncEvent | S→C | 训练场状态同步（面板显示/隐藏、当前设置状态） |

#### 安全规则

- 所有操作仅在 `LOBBY` 状态下允许（服务端验证）
- 进入匹配/对决时，服务端自动：
  - 关闭无CD模式 (noCooldown = false, noCost = false)
  - 回满HP/MP
  - 清除所有训练假人
  - 重置等级为 1
- 防刷保护：TrainingEvent 每秒最多处理 5 次请求

### 2.6 边界条件

| 场景 | 处理方式 |
|------|---------|
| 开启无CD后切换英雄 | 新英雄继承无CD状态 |
| 假人达到上限(3)再生成 | 自动移除最早的假人 |
| 对决中断（掉线判负）返回大厅 | 重新显示面板，恢复训练场设置为默认 |
| 玩家掉线重连 | 训练场设置重置为默认（CD正常、等级1） |
| 多人服务器中 | 每个玩家独立的训练场设置，假人只有创建者可见（或所有人可见但互不影响） |

> 💡 [假设] 训练假人对所有大厅内玩家可见且可交互（多人练习场景），但每个玩家最多创建3个。如需改为私有假人，可后续调整。

## 第三章 验收标准

### 3.1 正常路径

| AC编号 | 验收标准 | 测试方法 |
|--------|---------|---------|
| AC-01 | 玩家加入服务器后，左上角自动显示训练场控制面板 | PlaySolo: 加入游戏，检查左上角面板是否出现 |
| AC-02 | 点击"冷却: OFF→ON"后，所有技能立即可释放（CD=0），再次释放技能后CD不进入冷却 | PlaySolo: 开启无CD，连续释放Q技能2次，检查无等待时间 |
| AC-03 | 开启无CD时，释放技能不消耗蓝量/能量 | PlaySolo: 开启无CD，选廉颇，连续释放Q检查怒气不变 |
| AC-04 | 关闭无CD后，技能恢复正常冷却和消耗 | PlaySolo: 关闭无CD，释放Q，检查CD倒计时正常显示 |
| AC-05 | 点击"回满HP/MP"后，生命值、蓝量/能量回满至最大值 | PlaySolo: 受伤后点击回满，检查Humanoid.Health == MaxHealth |
| AC-06 | 点击"生成假人"后，玩家前方10studs处出现训练假人，头顶有血条 | PlaySolo: 点击生成，检查假人位置和血条 |
| AC-07 | 攻击训练假人时，显示浮动伤害数字（红色物理/紫色法术） | PlaySolo: 用拉克丝Q攻击假人，检查紫色数字；用后羿普攻检查红色数字 |
| AC-08 | 训练假人不会死亡，HP最低降到1，5秒后自动回满 | PlaySolo: 持续攻击假人，观察HP不归零，停止攻击后HP回满 |
| AC-09 | 最多3个假人，第4次生成时最早的假人被移除 | PlaySolo: 连续点4次生成，检查场景中只有3个假人 |
| AC-10 | 点击"清除假人"后，所有假人被移除 | PlaySolo: 生成2个假人后清除，检查场景中无假人 |
| AC-11 | 等级调整: 点+从Lv1升至Lv2，属性(HP/ATK等)正确更新 | PlaySolo: 升级后检查属性面板数值变化 |
| AC-12 | 点击"回到出生点"后，玩家传送回出生点并HP回满 | PlaySolo: 走远后点击，检查位置和HP |

### 3.2 边界条件

| AC编号 | 验收标准 | 测试方法 |

## 第四章 风险与依赖

### 4.1 依赖项

| 依赖 | 说明 | 状态 |
|------|------|------|
| BaseSkill 冷却系统 | 需要在 _startCooldown 中添加 noCooldown 检查 | ✅ 已有 (REQ-006) |
| StatsManager 属性系统 | 等级调整需要触发属性重算 | ✅ 已有 |
| LobbyManager 状态管理 | 需要钩入 LOBBY→MATCHING 状态切换清理训练场 | ✅ 已有 (REQ-004) |
| BuffSystem | 回满HP时需要清除负面Buff | ✅ 已有 (REQ-005) |
| RemoteEventInit | 需要注册新的 TrainingEvent / TrainingSyncEvent | ✅ 已有框架 |

### 4.2 风险项

| 风险 | 级别 | 缓解措施 |
|------|------|---------|
| 无CD模式被带入对决 | 🔴 高 | 服务端在状态切换时强制关闭，双重检查 |
| 假人性能问题 | 🟡 中 | 限制最大3个，R15 简单模型 |
| 多人服务器假人冲突 | 🟡 中 | 每人独立的假人列表，总量限制 |
