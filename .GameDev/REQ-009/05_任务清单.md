## T3: BaseSkill 添加 noCooldown 检查

| 属性 | 值 |
|------|-----|
| 文件 | `src/ServerScriptService/ServerModules/BaseSkill.lua` |
| 类型 | 修改 |
| 预估 | 8 行 |
| 依赖 | 无 |
| 状态 | ⬜ 待开发 |

**工作内容**:
1. 修改 `BaseSkill:CanCast(player)` — 新增可选参数 `player`:
   ```lua
   function BaseSkill:CanCast(player)
       if player and shared.TrainingManager and shared.TrainingManager.IsNoCooldown(player) then
           return true
       end
       return (os.clock() - self.LastCastTime) >= self:GetFinalCD()
   end
   ```
2. 修改 `BaseSkill:StartCooldown(player)` — 新增可选参数 `player`:
   ```lua
   function BaseSkill:StartCooldown(player)
       if player and shared.TrainingManager and shared.TrainingManager.IsNoCooldown(player) then
           return
       end
       self.LastCastTime = os.clock()
   end
   ```

**向后兼容**: player 为 nil 时走原逻辑

**验证**: 开启 noCooldown 后，CanCast 始终返回 true; StartCooldown 不设置 LastCastTime

## T4: TrainingManager 服务端核心 (新文件)

| 属性 | 值 |
|------|-----|
| 文件 | `src/ServerScriptService/TrainingManager.server.lua` |
| 类型 | 新增 |
| 预估 | 150 行 |
| 依赖 | T1 (RemoteEvent) |
| 状态 | ⬜ 待开发 |

**工作内容**:

1. **数据结构**:
   ```lua
   local trainingStates = {}  -- [Player] → { noCooldown, noCost }
   local dummies = {}          -- [Player] → { Model[] }
   local MAX_DUMMIES_PER_PLAYER = 3
   local MAX_TOTAL_DUMMIES = 15
   local RATE_LIMIT = 0.2  -- 每次操作间隔 0.2s
   ```

2. **核心函数**:
   - `toggleCD(player, enabled)` → 设置 noCooldown + noCost, 如果开启则立即重置所有技能CD(同步CD=0给客户端)
   - `refreshHP(player)` → Humanoid.Health = MaxHealth + MP回满 + EnergySystem 回满 + BuffSystem:RemoveAllEffects
   - `spawnDummy(player)` → 在玩家前方 10 studs 创建 R15 Dummy (Anchored, HP=10000, 不死机制, BillboardGui 血条)
   - `clearDummies(player)` → 销毁所有假人
   - `setLevel(player, level)` → 调用 StatsManager.SetLevel
   - `resetPosition(player)` → CFrame 传送到出生点 + refreshHP

3. **Rate limiter**: 每个玩家记录 lastActionTime, 间隔 < 0.2s 拒绝

4. **状态监听**: 使用 `task.spawn` 循环检测玩家状态变化 (每 0.5s):
   ```lua
   -- 当 LobbyManager 状态从 LOBBY 变为 MATCHING/DUELING 时:
   -- → resetTrainingState(player) → 清理假人 + 重置设置 + sync
   ```
   
5. **训练假人不死机制**:
   ```lua
   humanoid.HealthChanged:Connect(function(health)
       if health <= 1 then
           humanoid.Health = 1  -- clamp, 不死亡
       end
   end)
   -- HP 回满 loop:
   task.spawn(function()
       while dummy.Parent do
           task.wait(5)
           humanoid.Health = humanoid.MaxHealth
       end
   end)
   ```

6. **shared API 暴露**:
   ```lua
   shared.TrainingManager = {
       IsNoCooldown = function(player) ... end,
       IsNoCost = function(player) ... end,
       ResetTrainingState = function(player) ... end,
   }
   ```

7. **清理**: PlayerRemoving → clearDummies + 移除 trainingStates

**验证**: 全部 F1-F5 功能正常, 状态切换时正确重置
