## 第二章 系统架构

### 2.1 架构概览

```
改造范围（仅客户端UI层）:

Client.client.lua (入口)
  │
  ├── isMobile = true
  │     ├── [改造] 大厅阶段: 创建 MobileUI ScreenGui + 大厅功能按钮
  │     │     ├── UI_VirtualJoystick.Init() — 大厅模式(静态指示)
  │     │     ├── UI_SkillButtons.Init() — 大厅模式(锁定态)
  │     │     ├── 训练场按钮(新建, 替代PC版UI_TrainingPanel)
  │     │     ├── 匹配按钮(新建, 替代PC版UI_MatchButton)
  │     │     └── HeroSelectUI.Show()
  │     │
  │     └── [保留] onHeroConfirmed: 激活输入系统(MobileInputManager)
  │           ├── UI_VirtualJoystick → 激活模式
  │           ├── UI_SkillButtons → 显示技能图标
  │           ├── UI_MobileHUD → 战斗HUD(改造布局)
  │           └── UI_Minimap → 小地图(调整位置)
  │
  └── isMobile = false
        └── [完全不变] UIManager.Init() + OverheadUI + UI_TrainingPanel + StatsBinding
```

### 2.2 关键设计决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 大厅阶段摇杆/技能按钮何时创建 | 在 `Client.client.lua` 大厅初始化阶段就创建（英雄选择之前） | 策划案要求"第一秒就看到" |
| 摇杆如何区分大厅/战斗模式 | 新增 `UI_VirtualJoystick.SetLobbyMode(true/false)` API | 大厅模式=静态指示不响应输入，战斗模式=正常操控 |
| 技能按钮如何显示锁定态 | `UI_SkillButtons.Init(parent, nil)` 传入 nil skillSlots 时显示锁定态 | 复用现有Init接口，空参数=锁定 |
| 训练场面板怎么适配移动端 | 创建新的移动端训练场按钮 + 复用 `UI_TrainingPanel` 逻辑 | 仅 UI 布局不同，核心功能(TrainingEvent)不变 |
| MobileConfig参数如何更新 | 新增弧形布局参数 + 摇杆默认位置参数 | 集中配置，策划可调 |
| StatsBinding移动端适配 | 移动端跳过 StatsBinding.Init()，UI_MobileHUD 自行监听 Attributes | UI_MobileHUD 已有独立的 HP/MP 监听逻辑(REQ-011) |

### 2.3 模块改造矩阵

| 文件 | 改造类型 | 改动规模 | 核心改动 |

**总预估: ~270行改动**

### 3.2 Client.client.lua 改造伪代码

```lua
-- ========== 基础UI初始化 ==========
if isMobile then
    -- ===== 移动端路径 =====
    local playerGui = player:WaitForChild("PlayerGui")
    local mobileGui = Instance.new("ScreenGui")
    mobileGui.Name = "MobileUI"
    mobileGui.ResetOnSpawn = false
    mobileGui.Parent = playerGui

    local mobileFrame = Instance.new("Frame")
    mobileFrame.Name = "MobileFrame"
    mobileFrame.Size = UDim2.new(1, 0, 1, 0)
    mobileFrame.BackgroundTransparency = 1
    mobileFrame.Parent = mobileGui

    -- 大厅阶段就初始化摇杆(静态指示模式)
    UI_VirtualJoystick.Init(mobileFrame)
    UI_VirtualJoystick.SetLobbyMode(true)

    -- 大厅阶段就初始化技能按钮(锁定态)
    UI_SkillButtons.Init(mobileFrame, nil)  -- nil = 锁定态

    -- 创建移动端大厅功能按钮
    createMobileLobbyButtons(mobileFrame)  -- 训练场+匹配按钮

    -- OverheadUI 两端通用
    OverheadUI.Init()

    -- 弹出英雄选择
    HeroSelectUI.Show(9999)
else
    -- ===== PC端路径（完全不变）=====
    UIManager.Init()
    OverheadUI.Init()
    UI_TrainingPanel.Init()
    local UI_HUD = UIManager.GetHUD()
    StatsBinding.Init(UI_HUD)
    HeroSelectUI.Show(9999)
end

-- onHeroConfirmed 改造:
-- 移动端: 不再创建 MobileUI ScreenGui (已在大厅创建)
-- 移动端: 调用 UI_VirtualJoystick.SetLobbyMode(false) 激活
-- 移动端: 调用 UI_SkillButtons.UpdateSkills(skillSlots) 更新图标
-- 移动端: 初始化 MobileInputManager (不变)
-- 移动端: 初始化 UI_MobileHUD + UI_Minimap (从onHeroConfirmed移到此处不变)
```
