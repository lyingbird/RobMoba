# 第一章 设计概述

## 1.1 设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|---------|
| **第一秒就对** | 玩家进入游戏的第一秒就看到移动端专属UI，不是PC版HUD | Device Emulator启动后无PC元素 |
| **大厅有交代** | 大厅模式下UI不是空白，摇杆指示、英雄选择、功能按钮一应俱全 | 未选英雄时所有区域有占位UI |
| **王者同布局** | 布局与王者荣耀标准一致，老玩家0学习成本 | 核心元素位置差异<5% |
| **PC零影响** | PC端玩家完全感受不到本次改动 | isMobile=false 时行为不变 |

## 1.2 设计原则

- **简洁性**: 大厅模式精简为3个核心入口（英雄选择、训练场、匹配），不堆砌功能
- **一致性**: 大厅→战斗UI过渡平滑，摇杆/技能按钮位置不跳变
- **反馈性**: 大厅按钮有触摸缩放反馈，状态切换有淡入淡出过渡
- **容错性**: 未选英雄时触碰摇杆区无反应（不报错不卡死），技能按钮显示锁定态

## 1.3 信息层级

```
═══════ 大厅模式 ═══════
优先级1（始终显示）: 英雄选择面板（首次弹出）
优先级2（始终显示）: 摇杆静态指示 | 技能按钮锁定态 | 功能按钮(训练场/匹配)
优先级3（选完英雄后）: 英雄小面板 | 摇杆激活 | 技能按钮解锁

═══════ 战斗模式（沿用REQ-011）═══════
优先级1（始终显示）: 虚拟摇杆 | 技能按钮+CD | 普攻按钮 | HP/MP条
优先级2（始终显示）: 击杀比分 | 对局时间 | 等级
优先级3（事件触发）: 击杀播报 | 复活倒计时
优先级4（按需显示）: 小地图
```

## 1.4 与REQ-011差异

> 本次UX设计是REQ-011的**迭代优化**，不是全新设计。核心交互流程（移动/技能释放/普攻）完全复用REQ-011，本次聚焦以下改动：

| 改动点 | REQ-011 | REQ-015 |
|--------|---------|---------|
| PC端UI | 无条件初始化，手机也显示 | 条件隔离，手机不显示PC HUD |
| 大厅阶段 | 无移动端UI，只有英雄选择弹窗 | 完整的移动端大厅UI层 |
| 摇杆时机 | 选完英雄后才出现 | 大厅就有静态指示 |
| 技能按钮时机 | 选完英雄后才出现 | 大厅有锁定态占位 |
| HUD布局 | 基础信息栏 | 王者荣耀标准布局 |
| 小地图位置 | 基础位置 | 左上角标准位置(2%,15%) |
| 训练场/匹配按钮 | 沿用PC版 | 移动端专属触屏友好按钮 |

## 2.5 技能按钮弧形面板

### 弧形布局视觉

```
                 [W] ← 165°
              [Q] ↖   [R] ← 135°    Q/W/R: 11% 屏幕短边(直径)
                        ↙
                   ◉[ATK]           ATK: 14% 屏幕短边(直径)
                                     中心: (88%, 82%)
弧形半径 = ATK直径 × 1.3
弧形起始角 = 135°(从ATK中心计算)
每个按钮间隔 = 30°
```

### 技能按钮状态矩阵

| 状态 | 图标 | 背景 | 边框 | 覆盖层 | 触摸 |
|------|------|------|------|--------|------|
| 大厅-锁定(未选英雄) | "?" 问号 | 深灰(0.7) | 暗灰 | 无 | ❌ |
| 可用 | 技能图标 | 深色(0.3) | 亮色(英雄主题色) | 无 | ✅ 按住→方向轮盘/松手释放 |
| CD冷却中 | 技能图标(灰色) | 深灰(0.7) | 暗灰 | 顺时针扫描遮罩 + 白色倒计时数字 | ❌ |
| MP不足 | 技能图标(蓝灰) | 深灰(0.6) | 蓝色闪烁(0.5s周期) | 蓝色半透明 | ❌ |
| 按住/拖拽中 | 技能图标(高亮) | 英雄主题色(0.5) | 白色发光 | 方向轮盘展开 | ✅ 拖拽瞄准 |

### 普攻按钮特殊设计

普攻按钮是最大、最显眼的按钮（14% 屏幕短边），因为它是玩家右手大拇指最自然触及的位置：
- **默认态**: 剑型图标 + 英雄主题色圆形背景
- **触摸态**: 缩小至95% + 白色发光环（0.1s）
- **CD中**: 灰色 + 旋转CD指示（普攻CD很短，用旋转而非扇形）

## 3.2 大厅UI交互流程

### 训练场按钮交互

```
触摸[训练场按钮]
  → 按钮缩放至95%(0.1s)
  → 训练场面板从底部滑入(0.3s)
    → 触摸功能按钮(按钮缩放反馈)
      → 发送TrainingEvent到服务端
      → 等待TrainingSyncEvent反馈
    → 触摸[✕]关闭或面板外点击
      → 面板滑出(0.2s)
```

### 匹配按钮交互

```
触摸[匹配按钮]
  → 按钮缩放至95%(0.1s)
  → 发送匹配请求
  → 按钮变红色 "❌ 取消匹配"
  → 匹配成功 → 3秒倒计时 → 传送
  → 再次触摸 → 取消匹配 → 恢复蓝色
```

### 英雄切换交互

```
触摸[切换英雄按钮]
  → 英雄选择面板弹出(全屏)
  → 选择新英雄 → 确认
  → 技能按钮图标更新
  → 面板关闭
```
