# 第一章 设计概述

## 1.1 设计目标

- **DG-1: 零学习成本** — 王者荣耀玩家拿起来就会用，按住拖拽松手的肌肉记忆直接迁移
- **DG-2: 操作不打断战斗** — 技能释放全程 1-2 步完成（按住→松手），不弹额外确认框
- **DG-3: 所见即所得** — 指示器精准反映技能实际影响范围，消除"瞄的和打的不一样"
- **DG-4: PC端零影响** — 所有改动仅影响移动端路径，PC端UI/操控完全不变

## 1.2 设计原则

- **简洁性**: 战斗中屏幕上同一时刻最多只存在 1 个指示器，避免视觉噪音
- **一致性**: 所有技能按钮共享同一套触摸手势（按住→拖拽→松手），self 类型简化为点按即放
- **反馈性**: 每个操作阶段都有明确的视觉反馈 — 按下(缩放)、瞄准(蓝色发光+指示器)、取消(红色+✕)、释放(白色闪光)
- **容错性**: 误触可通过拖回取消区撤销，拖出屏幕不会丢失操作（按最后方向释放）

## 1.3 设计背景

### 当前问题

玩家在移动端进入训练场后，看到的是 PC 端的技能栏布局（底部横排 QWERF 键位 + 左侧属性面板 + 顶部 VS 比分），完全无法用触屏操作。

### 王者荣耀参考

王者荣耀的移动端布局是手游 MOBA 的黄金标准：
- 左下虚拟摇杆（已有 ✅）
- 右下弧形排列技能按钮（已有 ✅，需升级指示器）
- 顶部精简信息栏（已有模块 UI_MobileHUD，未集成 ❌）
- 技能按住拖拽时 3D 世界中显示瞄准指示器（未实现 ❌）

### 已有可复用资源

| 模块 | 复用情况 |
|------|---------|
| `UI_VirtualJoystick` | ✅ 完全复用，无需改动 |
| `UI_SkillButtons` | ✅ 复用按钮布局+8种状态，升级指示器渲染 |
| `UI_MobileHUD` | ✅ 复用全部功能，仅需集成到初始化流程 |
| `MobileConfig` | ✅ 复用参数体系，新增指示器参数 |
| `UITheme` | ✅ 复用配色规范（HUD暗色调、ACCENT蓝色发光） |

### 元素列表

| 元素 | 类型 | 位置 (UDim2) | 尺寸 | 交互 | ZIndex |
|------|------|-------------|------|------|--------|

### 分层架构

```
PlayerGui
├── MobileUI (ScreenGui, ResetOnSpawn=false, ZIndexBehavior=Sibling)
│   └── MobileFrame (Frame, 全屏, BackgroundTransparency=1)
│       ├── VirtualJoystick 区域 (左下)
│       └── SkillButtons 区域 (右下)
├── MobileHUDGui (ScreenGui, DisplayOrder=5)
│   └── MobileHUD (TopBar + KillNotify + RespawnOverlay)
└── 🚫 不创建 HUD (PC端ScreenGui)
```

> **关键**: `MobileUI` 和 `MobileHUDGui` 是两个独立的 ScreenGui，避免 ZIndex 冲突。

## 2.4 LINE指示器

### 玩家感受描述

> 想象你是后羿，按住R技能。手指按下的瞬间，脚下出现一道金黄色的光线，笔直延伸到100 studs远。你拖拽手指旋转方向，光线跟着你的手指实时转动——就像王者荣耀里瞄准后羿大招时一模一样。松手的瞬间，光线闪亮一下消失，大招飞出去了。

### 3D世界渲染 — ASCII侧视图

```
                    ▲ 箭头 (三角装饰, 宽3 stud)
                    │
────────────────────┤  ← 方向线本体 (长度=SkillRange, 宽1.5 stud, Neon材质)
                    │
    ◯ 起始圆环      │  ← 英雄脚下 (半径2 stud, 0.2 stud离地)
  [英雄]           │
```

### 3D世界渲染 — ASCII俯视图

```
                         Range=100 stud (后羿R)
    ←───────────────────────────────────────────────→
    
    ◯ 英雄位置        ━━━━━━━━━━━━━━━━━━━━━━━━━━▶
                      ↑                           ↑
                    起始圆                       箭头
                    
    手指旋转方向 ↻ → 整条线绕英雄旋转
```

### 颜色映射

| 英雄 | 指示器颜色 | RGB | 透明度 |
|------|-----------|-----|--------|
| 安琪拉 | 橙红 | (255, 100, 50) | 0.4 |
| 后羿 | 金黄 | (255, 200, 50) | 0.4 |
| 廉颇 | 冰蓝 | (100, 200, 255) | 0.4 |
| Lux | 淡紫 | (200, 150, 255) | 0.4 |

### 取消态视觉

手指拖回取消区时:
- 方向线颜色 → 红色半透明 `(255, 80, 80)` 复用 `MobileConfig.AIM_CANCEL_COLOR`
- 方向线透明度 → 0.6（更淡）
- 按钮上显示 ✕ 标记

## 2.5 CIRCLE_SELF指示器

### 玩家感受描述

> 你是后羿，点按Q技能。一瞬间脚下绽放出一个金黄色的圆环，标记出多重箭矢的作用范围(20 stud)。圆环像水波一样微微脉动了一下就消散了——技能已经释放。整个过程不到0.2秒，完全不打断你的走位。

### 3D世界渲染 — ASCII俯视图

```
        Range = 20 stud (后羿Q)
    ←──────────────────────────→
    
            ╭─────────╮
          ╭─┤ 脉冲边缘 ├─╮      ← 边缘有微妙的缩放脉冲动画
         │  ╰─────────╯  │
         │                │
         │    ◯ 英雄      │      ← 圆心 = HumanoidRootPart
         │                │
         │                │
          ╰──────────────╯
          
    圆形 Part (Cylinder, Neon, 扁平)
    高度 = 0.1 stud, 离地 0.2 stud
```

### 生命周期

```
点按 → 创建/显示圆形 → 0.15秒闪光脉冲 → 淡出消失 → 技能释放
```

> CIRCLE_SELF 不需要拖拽瞄准，点按即放。指示器的作用是"告诉玩家技能范围有多大"而不是"让玩家瞄准"。

# 第三章 交互流程

## 3.1 技能释放主流程

### directional/默认 类型 (LINE指示器)

```
玩家按住技能按钮
    │
    ▼
按钮状态 → AIMING (蓝色发光边框)
2D方向轮显示 (按钮上的aimLine)
3D LINE指示器创建并显示
    │
    ▼
玩家拖拽手指 ←──────────────── 每帧更新
    │                            │
    ├── 距离 > 取消阈值 ────────┤  2D aimLine旋转
    │   (正常瞄准)               │  3D 方向线旋转
    │                            │
    ├── 距离 < 取消阈值 ────────┤  按钮边框→红色
    │   (取消区)                 │  显示 ✕ 标记
    │                            │  3D指示器变红
    │                            │
    ▼                            │
玩家松手 ◄───────────────────────┘
    │
    ├── 在取消区内 → 技能不释放 → 按钮回IDLE → 指示器消散(0.1s)
    │
    └── 在取消区外 → 技能释放 → 按钮→COOLDOWN → 指示器闪光(0.15s)→消失
                     │
                     └── FireServer(CastSkillEvent, skillId, direction)
```

### self 类型 (CIRCLE_SELF)

```
玩家点按技能按钮
    │
    ▼
按钮状态 → INSTANT_CAST (缩放动画0.08s)
3D CIRCLE_SELF 闪现(0.15s脉冲)
FireServer(CastSkillEvent, skillId, nil)
    │
    ▼
按钮状态 → COOLDOWN (灰色遮罩+秒数)
CIRCLE_SELF 淡出消失
```

### channel 类型 (安琪拉R, 无指示器)

```
玩家点按R技能按钮
    │
    ▼
按钮状态 → INSTANT_CAST → COOLDOWN
FireServer(CastSkillEvent, skillId, currentFacingDirection)
    │
    ▼
服务端开始引导 → 引导期间由服务端控制光束方向
(移动端Phase 1: 自动追踪最近敌人)
```

## 3.2 取消机制流程

### 取消判定

```
手指位置 (touchPosition)
    │
    ▼
计算 distance = |touchPosition - buttonCenter|
计算 threshold = buttonRadius × AIM_CANCEL_THRESHOLD (0.3)
    │
    ├── distance < threshold → 进入取消区
    │   视觉: 按钮边框红色, 显示 ✕, 3D指示器变红变淡
    │   松手: 取消释放
    │
    └── distance >= threshold → 正常瞄准区
        视觉: 按钮边框蓝色, aimLine显示, 3D指示器正常色
        松手: 释放技能
```

### 取消区视觉反馈

```
正常瞄准态:                    取消态:
┌──────────┐                  ┌──────────┐
│ ┌──────┐ │ ← 蓝色边框      │ ┌──────┐ │ ← 红色边框
│ │ 技能 │ │                  │ │  ✕   │ │ ← 取消标记覆盖图标
│ │ 图标 │ │                  │ │      │ │
│ └──────┘ │                  │ └──────┘ │
│    ╱     │ ← aimLine(黄)    │          │ ← aimLine隐藏
└──────────┘                  └──────────┘
```

## 3.3 异常流程

| 异常情况 | 处理方式 | 用户反馈 |
|----------|----------|----------|
| 瞄准中角色被眩晕/击飞 | 强制取消当前瞄准，指示器消失 | 按钮切换到 DISABLED 状态(🔒图标)，全屏短暂红色边框闪烁(0.1s) |
| 瞄准中角色死亡 | 强制取消瞄准，指示器消失 | 所有按钮切换到 DEAD 状态，复活倒计时遮罩显示 |
| CD中点按技能 | 忽略触摸 | 按钮短暂闪红(BTN_FLASH_COLOR_CD, 0.15s)提示正在CD |
| 蓝量不足点按技能 | 忽略触摸 | 按钮短暂抖动(水平±3px, 0.2s) + MP条短暂高亮闪蓝(0.3s) |
| 两根手指同时按两个技能 | 只响应先触发的那个 | 第二个按钮无反应(全局 aimingSlot 锁) |
| 拖拽手指移出屏幕边缘 | 保持最后有效方向 | 松手时按最后方向释放 |
| 引导技能(安琪拉R)中点其他技能 | 忽略触摸 | 其他按钮显示DISABLED状态直到引导结束 |

# 第四章 交互规范

## 4.1 技能按钮状态定义

| 状态 | 触发条件 | 边框颜色 | 背景 | 图标 | 额外元素 | 可交互？ |
|------|----------|---------|------|------|----------|---------|
| **IDLE** | 默认/CD结束/取消后 | `Theme.SLOT_BORDER` 暗灰 | 正常 `Theme.SLOT_BG` | 正常 | 无 | ✅ |
| **INSTANT_CAST** | 点按self/channel | — | 缩放0.9x→1.0x | 正常 | 无 | ❌(瞬间) |
| **AIMING** | 按住directional/area | `Theme.ACCENT_GLOW` 蓝色 | 正常 | 正常 | aimLine + 3D指示器 | ✅(拖拽) |
| **CANCEL** | AIMING + 拖回取消区 | `AIM_CANCEL_COLOR` 红色 | 正常 | ✕覆盖 | 3D指示器变红 | ✅(松手取消) |
| **RELEASING** | 松手释放 | 白色闪光 | 白色闪0.15s | 正常 | 3D指示器闪光消失 | ❌(瞬间) |
| **COOLDOWN** | 释放后 | `Theme.SLOT_BORDER` 暗灰 | 灰色遮罩(0.7透明度) | 暗淡 | CD秒数文字(白色粗体) | ❌(闪红反馈) |
| **NO_MANA** | 蓝量不足 | `Theme.MP_BLUE` 蓝色 | 暗淡(0.4透明度) | 暗淡 | 无 | ❌(抖动反馈) |
| **DISABLED** | CC控制中 | `Theme.SLOT_BORDER` | 暗淡(0.4透明度) | 🔒覆盖 | 无 | ❌ |
| **DEAD** | 角色死亡 | 无 | 全暗(0.8透明度) | 不可见 | 无 | ❌ |

### 状态优先级 (高→低)

```
DEAD > DISABLED > COOLDOWN > NO_MANA > AIMING/CANCEL/RELEASING/INSTANT_CAST > IDLE
```

> 高优先级状态会覆盖低优先级。例如：AIMING中被眩晕 → 强制切到DISABLED。
