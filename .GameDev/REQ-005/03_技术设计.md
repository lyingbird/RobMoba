## 五、数据流设计

### 5.1 效果施加流程

```
技能命中触发
    │
    ▼
Skill_XXXX:OnCast()
    │ BuffSystem:ApplyEffect(source, target, effectId)
    ▼
BuffSystem:ApplyEffect()
    │
    ├─ 1. 读取 EffectConfig[effectId]
    ├─ 2. _checkMutex → 移除同互斥组旧 Buff
    ├─ 3. _handleStacking → 处理叠加/替换/刷新
    ├─ 4. 创建 BuffInstance → 注册到 activeBuffs
    │
    ├─ 5. 即时效果（Damage/Shield）
    │     └─ EffectExecutor:Execute()
    │
    └─ 6. 持续效果（CC/DoT/HoT/StatMod）
          ├─ CC: EffectExecutor:_executeCC() → 修改 WalkSpeed/Anchored
          ├─ StatMod: EffectExecutor:_executeStatMod() → 修改属性
          └─ DoT/HoT: 注册 tick，由 Heartbeat 驱动
```

### 5.2 Heartbeat 循环

```
每帧 RunService.Heartbeat:
    for characterModel, buffs in pairs(activeBuffs) do
        for instanceId, buff in pairs(buffs) do
            local elapsed = now - buff.startTime
            
            -- Tick 检查 (DoT/HoT)
            if buff.tickInterval then
                if now - buff.lastTickTime >= buff.tickInterval then
                    EffectExecutor:_executeTick(buff)
                    buff.lastTickTime = now
                end
            end
            
            -- 到期检查
            if elapsed >= buff.duration then
                _expireBuff(characterModel, buff)
                buffs[instanceId] = nil
            end
        end
    end
```

## 十、发现的额外问题（建议一并修复）

### 10.1 CombatUtils 距离计算 Bug

```lua
-- 当前代码（有误）：
local distSq = (targetPos - position).Magnitude  -- 这已经是标量距离
distSq = distSq * distSq  -- 这变成了距离的平方
-- 然后与 radius * radius 比较 → 比较 dist^2 vs radius^2 ✅
-- 等等，重新看：.Magnitude 返回标量，再平方...
-- 实际上这是正确的!!! .Magnitude = dist, dist*dist = dist^2, vs radius^2
-- 但更规范的写法应该用 .Magnitude 直接比 radius：
-- if dist <= radius then
```

> 经重新审查：代码虽然写法不规范（取 Magnitude 再平方 vs 直接用 Magnitude 比 radius），但数学上 dist^2 vs radius^2 是等价的。**不是 Bug**，只是代码风格问题。不在本次修复。
