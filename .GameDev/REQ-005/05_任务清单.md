## Task 6: BuffSystem + EffectExecutor

**涉及文件**:
- 新建 `src/ServerScriptService/ServerModules/BuffSystem.lua` (~200行)
- 新建 `src/ServerScriptService/ServerModules/EffectExecutor.lua` (~180行)

**执行内容**:

**6a. BuffSystem.lua**:
1. 实现 `activeBuffs` 数据结构：`activeBuffs[characterModel][instanceId] = BuffInstance`
2. 实现 `ApplyEffect(source, target, effectId)` — 核心入口
3. 实现叠加规则处理：Replace/Stack/Refresh/Independent
4. 实现互斥组检查
5. 实现 Heartbeat 循环：到期检查 + Tick 执行
6. 实现 `RemoveEffect` / `RemoveAllEffects` / `HasEffect` / `HasCCType` / `GetBuffStacks`
7. 绑定 `Humanoid.Died` → `RemoveAllEffects` 清理
8. 绑定 `Players.PlayerRemoving` → 清理该玩家相关 Buff

**6b. EffectExecutor.lua**:
1. 实现 `Execute(source, target, effectConfig)` 分发入口
2. 实现 `_executeDamage` — `Humanoid:TakeDamage(amount)`
3. 实现 `_executeCC`:
   - Stun/Knockup → `Anchored = true`
   - Slow → `WalkSpeed *= (1 - percent)`
   - Root → `Anchored = true`（不禁止施法）
   - Silence → 设置 Attribute `CanCastSkill = false`
   - Disarm → 设置 Attribute `CanAutoAttack = false`
4. 实现 `_executeShield` — 设置 Attribute `ShieldAmount`
5. 实现 `_executeStatMod` — 根据 Stat/ModType 修改对应属性
6. 实现 `_executeDoT` / `_executeHoT` — 单次 Tick 执行，由 BuffSystem 定时调用
7. 实现 `_revertCC` / `_revertStatMod` — 效果到期时恢复原状

**关键设计决策**:
- Shield 伤害抵消：通过 Attribute `ShieldAmount`，在 TakeDamage 前检查并扣减
- CC 恢复：存储原始值（如原始 WalkSpeed），到期时恢复
- Heartbeat 遍历安全：先收集待移除列表，遍历后统一移除（避免遍历中修改 table）
