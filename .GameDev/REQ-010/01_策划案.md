# REQ-010: 训练场假人无法被命中/伤害

## Bug 描述

用户实际测试发现 REQ-009 训练场的假人存在以下问题：
1. **不会受到伤害** — 技能和普攻均无法对假人造成伤害
2. **不会被击飞** — CC效果（击飞等）不作用于假人
3. **没有伤害飘字** — 无浮动伤害数字显示

## 根因分析（已完成）

**核心根因**：`CombatUtils.isEnemy()` 拒绝训练假人作为有效目标
- 假人位于 `workspace` 根目录（不在 `workspace.敌人` 文件夹下）
- 假人不是任何 Player 的 Character
- 因此 `isEnemy()` 返回 false，所有 5 个 Archetype + AutoAttackManager 均无法命中假人

**次要问题**：
- 假人无飘字系统（EnemyClass 有但假人不使用 EnemyClass）
- 假人 Anchored=true 可能影响击飞 CC 效果

## 影响范围

- `CombatUtils.lua` — isEnemy() 和 getEnemiesInRange()
- `TrainingManager.server.lua` — 假人创建逻辑
- 所有 5 个 Archetype 技能 + AutoAttackManager — 均被 CombatUtils 拦截
