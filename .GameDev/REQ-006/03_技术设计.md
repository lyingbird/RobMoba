### 3.3 关键流程

#### 技能释放流程（迁移后）

```
Client: InputManager 按键 → CastSkillEvent:FireServer(skillId, direction)

Server: PlayerSkillManager:OnCastSkill(player, skillId, direction)
  → 验证 CD/状态
  → SkillModuleMap[skillId] → skillInstance
  
  [新流程] skillInstance 继承了 Archetype:
  → ProjectileSkill:OnCast(player, targetPos)
    → config = self:GetProjectileConfig()    -- 子类提供配置
    → bullet = self:_createBullet(config)    -- Archetype 通用逻辑
    → 碰撞检测 → 命中
    → SkillHelper.ApplyEffects(self, source, target, config.OnHitEffects)
                                              ↓
                               BuffSystem:ApplyEffect(source, target, effectId)
                                              ↓
                               EffectExecutor:Execute(effectConfig)
                                              ↓
                               Damage/CC/Shield/... 实际执行
    → self:OnProjectileHit(player, target, hitPos)  -- 子类自定义回调
    → SkillPresenter:PlayPresentation(...)   -- 演出(不变)

Server → Client: SkillVFXEvent / SyncCooldownEvent (不变)
```

#### EffectExecutor Knockup 增强流程

```
BuffSystem:ApplyEffect(source, target, effectId)
  → EffectExecutor:Execute(source, target, effectConfig, buff)
  → effectConfig.Type == "CC" and effectConfig.CCType == "Knockup"
  
  [现有] _executeCC("Knockup"):
    humanoid.WalkSpeed = 0
    rootPart.Anchored = true
  
  [增强] _executeCC("Knockup"):
    humanoid.WalkSpeed = 0
    rootPart.Anchored = true
    -- 新增: Tween 上抛动画
    local height = effectConfig.KnockupHeight or 8
    local upTime = duration * 0.4
    local downTime = duration * 0.6
    TweenService:Create(rootPart, {upTime}, {CFrame = rootPart.CFrame + Vector3.new(0, height, 0)}):Play()
    task.delay(upTime, function()
        TweenService:Create(rootPart, {downTime}, {CFrame = originalCFrame}):Play()
    end)
  
  [增强] _revertCC("Knockup"):
    rootPart.Anchored = false
    humanoid.WalkSpeed = originalSpeed  -- 从 savedValues 恢复
```

### 4.3 GetXxxConfig() 返回值规范

```lua
-- ProjectileConfig
{
    Speed = number,                     -- 弹道速度 (studs/s)
    Size = Vector3,                     -- 弹体尺寸
    Color = Color3,                     -- 弹体颜色
    Material = Enum.Material,           -- 弹体材质
    MaxLifetime = number,               -- 最大存活时间 (默认3s)
    MaxPierceCount = number,            -- 穿透数 (默认1=不穿透)
    OnHitEffects = { number },          -- 命中效果ID列表
    OnHitCC = { number },              -- 命中CC效果ID列表
}

-- AreaConfig
{
    Radius = number,                    -- 区域半径
    Duration = number,                  -- 持续时间
    TickInterval = number,              -- Tick间隔 (默认0.5s)
    TickEffects = { number },           -- 每Tick效果ID
    OnEnterEffects = { number },        -- 进入区域效果(可选)
    OnExpireEffects = { number },       -- 区域消失效果(可选)
    CanRecast = boolean,                -- 是否支持Recast引爆(默认false)
}

-- DashConfig
{
    Speed = number,                     -- 冲刺速度
    Width = number,                     -- 碰撞检测宽度
    MaxRange = number,                  -- 最大距离 (从 Config.Range 读取)
    OnDashHitEffects = { number },      -- 路径命中效果
    OnDashHitCC = { number },          -- 路径命中CC
    LockMovement = boolean,             -- 施法者锁定移速 (默认true)
}

-- BeamConfig
{
    Width = number,                     -- 激光宽度
    Range = number,                     -- 射程 (从 Config.Range 读取)
    Duration = number,                  -- 持续时间 (Channel模式)
    TickInterval = number,              -- Channel模式Tick间隔
    TickEffects = { number },           -- 每Tick效果
    Mode = "Instant" | "Channel",       -- 瞬发 / 引导
    TrackMouse = boolean,               -- Channel模式是否追踪鼠标(默认false)
}

-- InstantConfig
{
    SelfEffects = { number },           -- 对自身施加效果
    TargetEffects = { number },         -- 对目标施加效果(可选)
    AreaRadius = number,                -- 如果有AOE范围(可选)
    AreaEffects = { number },           -- AOE效果(可选)
}
```

## 6. 技术风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| Knockup Tween 与 HeroAnimator 冲突 | 击飞时骨骼动画可能被 Tween 覆盖 | 中 | Knockup 只修改 CFrame.Position，不改旋转；HeroAnimator 修改关节 Motor6D，不冲突。但需 PlaySolo 验证 |
| AngelaQ 多弹散射需重写 OnCast | 5 发散射弹幕不适合标准 ProjectileSkill:OnCast | 低 | AngelaQ 继承 ProjectileSkill 但完全重写 OnCast()，复用 _createBullet + GetProjectileConfig |
| LianPoR 三段跺地需重写 OnCast | 3 段 AOE 的延迟+判定不适合标准 AreaSkill:OnCast | 低 | 同上，继承 AreaSkill 但重写 OnCast()，复用 SkillHelper.ApplyAreaEffects |
| 15 技能迁移过程中功能中断 | 迁移中的技能可能暂时不可用 | 中 | 分两批迁移。第一批 5 个验证骨架正确后再批量迁移。每技能迁移后立即 PlaySolo |
| SkillPresenter VFX 调用变化 | Archetype 通用 OnCast 中 SkillPresenter 调用时机可能与原实现不同 | 中 | 保持 SkillPresenter:PlayPresentation() 的调用位置与原技能一致。不修改 SkillPresenter 本身 |

## 9. 性能考量

| 关注点 | 预期指标 | 优化策略 |
|--------|----------|----------|
| Archetype 继承链查找 | 无可测量影响 | metatable 查找在 Luau 中极快(<1μs)，3 层继承不影响性能 |
| AreaSkill Tick 循环 | 每区域每 TickInterval 一次 | 使用 Heartbeat + 累计 deltaTime 判断，非 task.delay |
| DashSkill 路径检测 | 每帧(Heartbeat) | 冲刺只持续 0.5-1s，短暂的每帧检测无性能风险 |
| SkillHelper.ApplyEffects | 每次调用遍历 effectIds | 通常 1-3 个 effectId，遍历开销可忽略 |
| BeamSkill 持续扫射 | 每 TickInterval 做范围检测 | 使用 CombatUtils 的距离平方比较优化 |
