# 第一章 功能概述

参考王者荣耀移动端技能释放标准，重做整个移动端技能释放系统，实现6种指示器类型、统一触控释放范式（按下→拖拽→松手）、智能释放和取消框机制，使移动端玩家能直观、精准地释放所有类型技能。

## 1.1 设计目标

| 目标 | 描述 | 优先级 |
|------|------|--------|
| 技能可释放 | 移动端所有15个主动技能均可正常释放 | P0 |
| 指示器可视化 | 不同类型技能显示对应的3D指示器（线形/矩形/圆形/扇形/自身圆形） | P0 |
| 触控范式统一 | 所有技能遵循"按下→拖拽瞄准→松手释放"的统一操作范式 | P0 |
| 取消机制 | 右上角取消框，拖到叉号指示器变红，松手取消释放 | P0 |
| 智能释放 | 快速点按（无拖拽）时自动朝最近敌人方向释放 | P1 |
| 目标锁定框架 | target_lock 类型预留框架（当前无使用此类型的技能） | P2 |

## 1.2 用户故事

作为一个 **移动端 MOBA 玩家**，
我想要 **按下技能按钮后看到对应的技能指示器，拖拽手指调整方向/位置，松手释放技能**，
以便 **像玩王者荣耀一样精准释放技能，享受流畅的战斗体验**。

## 1.3 参考竞品

**王者荣耀技能释放范式**（用户提供截图参考）：
- 按下技能按钮 → 英雄脚下出现指示器 + 右上角出现取消框(X)
- 手指在技能按钮上拖拽 → 指示器实时跟随方向/位置
- 手指拖到取消框(X) → 指示器和范围圈变红色，表示将取消
- 松手（非取消区域） → 技能释放
- 松手（在取消区域） → 技能不释放，指示器消失
- 快速点按（无明显拖拽） → 自动朝最近敌人方向释放

# 第二章 功能详细设计

## 2.1 aimType体系重设计

### 2.1.1 新旧映射关系

当前技能配置中的 aimType 不统一（部分技能未设置），需要统一为新体系：

| 新aimType | 操作模式 | 指示器类型 | 对应现有值 | 说明 |
|-----------|---------|-----------|-----------|------|
| `"line"` | 方向拖拽型 | 线形指示器 | `"directional"` / 未设置+CastRule=Direction | 按住拖拽调整方向 |
| `"rect"` | 方向拖拽型 | 矩形指示器 | 无（新增） | 与line类似但宽度更大，后续贴图区分 |
| `"circle_drop"` | 位置拖拽型 | 圆形落点指示器 | `"area"` | 按住拖拽调整落点位置 |
| `"sector"` | 方向拖拽型 | 扇形指示器 | 无（新增） | 按住拖拽调整扇形方向 |
| `"self_circle"` | 点按即放型 | 自身圆形指示器 | `"self"` | 短按即释放，显示自身范围 |
| `"target_lock"` | 头像选择型 | 目标锁定指示器 | 无（新增，预留） | 点按弹出敌方头像列表选择 |

## 2.2 统一触控释放范式（Touch Lifecycle）

### 2.2.1 状态机

```
                    ┌──── 快速点按(< 200ms，无明显位移) ────→ [智能释放] → IDLE
                    │
[IDLE] ─→ 按下技能按钮 ─→ [PRESSED]
                              │
                    CD/蓝量不足 ─→ 抖动反馈 → IDLE
                              │
                    CD/蓝量充足 ─→ 根据aimType分支：
                              │
               ┌──────────────┼──────────────┐
               │              │              │
          方向拖拽型      位置拖拽型     点按即放型
        (line/rect/      (circle_drop)  (self_circle)
         sector)              │              │
               │              │         立即释放 → IDLE
               ↓              ↓
          [AIMING]       [TARGETING]
          拖拽更新方向   拖拽更新落点位置
               │              │
               ↓              ↓
          松手 → 检查取消区域：
               │
     ┌─────────┼─────────┐
     │                   │
  在取消区域          不在取消区域
     │                   │
  [CANCEL]          [RELEASE]
  清理指示器         FireServer
  → IDLE            → IDLE
```

### 2.2.2 操作模式详细描述

**方向拖拽型（line / rect / sector）**：
1. 按下技能按钮 → 英雄脚下显示指示器 + 射程环 + 取消框
2. 手指从按钮出发拖拽 → 指示器方向实时跟随（以角色为原点，手指方向为指示器方向）
3. 拖到取消区域 → 指示器变红
4. 松手（非取消） → 以当前方向释放技能
5. 松手（取消区域） → 取消释放

**位置拖拽型（circle_drop）**：
1. 按下技能按钮 → 英雄脚下显示射程环 + 落点圆形指示器（初始在角色正前方或最近敌人位置） + 取消框
2. 手指拖拽 → 落点圆形跟随移动（限制在射程范围内）
3. 拖到取消区域 → 指示器变红
4. 松手（非取消） → 在落点位置释放技能
5. 松手（取消区域） → 取消释放

**点按即放型（self_circle）**：
1. 按下技能按钮 → 短暂显示自身圆形指示器（显示影响范围）
2. 立即释放，无需拖拽（不显示取消框）
3. 💡[假设] self_circle 不需要取消机制，因为是即时效果

**目标锁定型（target_lock）**（P2预留）：
1. 按下技能按钮 → 弹出射程内敌方头像列表
2. 点选头像 → 锁定目标释放
3. 点取消或超时 → 取消

## 2.3 6种指示器详细设计

> 所有指示器使用 ViewportFrame + 3D Part 渲染（与PC端一致的方案A）

### 2.3.1 line 线形指示器

**外观**：从角色脚下延伸的窄矩形条，末端有箭头
**组成**：
- 填充矩形 Part（长=技能射程，宽=技能宽度或默认3studs）
- 左右边线 Part（宽0.15studs）
- 箭头 Part（末端三角形）
- 脚下原点圆 Cylinder Part
**颜色**：正常=技能色（半透明绿/蓝），取消=红色

### 2.3.2 rect 矩形指示器

**外观**：比line更宽的矩形区域（如Lux R终极闪光的宽矩形），后续贴图区分
**组成**：与line相同结构，但宽度更大（技能配置中的 `indicatorWidth` 字段）
**颜色**：同line

### 2.3.3 circle_drop 圆形落点指示器

**外观**：在目标位置的圆形区域
**组成**：
- 填充圆 Cylinder Part（直径=技能范围×2）
- 边缘环 Cylinder Part（直径稍大，薄环）
- 射程环 Cylinder Part（显示在角色脚下，表示可投放范围）
**颜色**：正常=半透明绿/蓝，取消=红色

### 2.3.4 sector 扇形指示器

**外观**：从角色脚下延伸的扇形区域
**组成**：
- 💡[假设] 用多个薄 Part 拼接出扇形效果（Roblox无原生扇形Mesh），或使用 WedgePart
- 扇形角度和半径从技能配置读取
**颜色**：同上

### 2.3.5 self_circle 自身圆形指示器

**外观**：角色脚下的圆形范围（表示自身技能影响范围）
**组成**：
- 填充圆 Cylinder Part（直径=技能范围×2）
- 边缘环 Cylinder Part
**颜色**：正常=半透明绿/蓝（短暂显示后消失）

### 2.3.6 target_lock 目标锁定指示器（P2预留框架）

**外观**：射程内敌方头像列表
**实现**：预留接口，暂不实现具体UI

## 2.4 取消框机制

### 2.4.1 取消框外观

参考王者荣耀（用户提供截图）：
- **位置**：屏幕右上角（避开技能按钮区域和摇杆区域）
- **外观**：圆形半透明背景 + 白色 X 图标
- **尺寸**：直径约 15% 屏幕高度

### 2.4.2 取消交互流程

1. **出现时机**：技能按下且进入 AIMING/TARGETING 状态时，取消框淡入显示
2. **取消判定**：手指当前位置与取消框中心距离 < 取消框半径 × 1.2（留容错余量）
3. **变红反馈**：当手指进入取消区域时：
   - 取消框 X 图标变为红色，取消框背景变为红色半透明
   - 所有指示器 Part 的颜色变为红色
   - 射程环也变为红色
4. **恢复反馈**：手指离开取消区域时：
   - 取消框恢复白色
   - 指示器恢复正常颜色
5. **消失时机**：技能释放或取消后，取消框淡出消失

### 2.4.3 不显示取消框的情况

- `self_circle` 类型（点按即放，无拖拽阶段）
- `target_lock` 类型（有独立的取消按钮）

## 2.5 智能释放

### 2.5.1 触发条件

快速点按技能按钮，手指在按钮上的停留时间 < 200ms，且移动距离 < 10px

### 2.5.2 释放逻辑

| aimType | 智能释放行为 |
|---------|------------|
| `line` / `rect` / `sector` | 朝最近敌人方向释放；无敌人则朝角色当前面朝方向 |
| `circle_drop` | 在最近敌人位置释放（限制在射程内）；无敌人则在角色正前方最大射程处 |
| `self_circle` | 直接释放（本身就是点按即放） |
| `target_lock` | 锁定最近敌人（预留） |

### 2.5.3 最近敌人检测

- 使用 `CombatUtils.getNearestEnemy(character, maxRange)` 获取最近敌人
- 检测范围 = 技能射程 × 1.5（略大于射程，给予更好的辅助瞄准体验）
- 💡[假设] 敌方阵营判断复用现有 CombatUtils.isEnemy 逻辑（含训练假人）

## 2.6 CastSkillEvent协议扩展

### 2.6.1 当前接口

```
CastSkillEvent:FireServer(skillId, direction)
-- direction: Vector3 方向向量
```

### 2.6.2 新接口

```
CastSkillEvent:FireServer(skillId, params)
-- params: table {
--   direction: Vector3?     -- 方向（line/rect/sector使用）
--   position: Vector3?      -- 世界坐标位置（circle_drop使用）
--   targetId: string?       -- 目标实例名（target_lock使用）
-- }
```

### 2.6.3 兼容性

- 服务端 PlayerSkillManager 需兼容新旧格式
- 如 params 是 Vector3（旧格式），自动包装为 `{ direction = params }`
- PC端继续使用旧格式 `(skillId, direction)` 不受影响

# 第三章 验收标准

> ⚠️ 每条标准必须是可量化、可在 Roblox Studio 中验证的

### 模块A: 触控状态机与智能释放

- [ ] **AC-001**: 按下 line/rect/sector 类型技能按钮后，进入 AIMING 状态，显示对应指示器
- [ ] **AC-002**: 按下 circle_drop 类型技能按钮后，进入 TARGETING 状态，显示落点圆形指示器
- [ ] **AC-003**: 按下 self_circle 类型技能按钮后，立即释放技能（可看到技能效果生效）
- [ ] **AC-004**: AIMING 状态下拖拽手指，指示器方向实时跟随（延迟 < 1帧）
- [ ] **AC-005**: TARGETING 状态下拖拽手指，落点圆形在射程范围内跟随移动
- [ ] **AC-006**: 松手时（非取消区域），技能正确释放，服务端收到正确参数
- [ ] **AC-007**: 快速点按（< 200ms且移动距离 < 10px）触发智能释放，自动朝最近敌人方向
