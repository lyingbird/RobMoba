# 第一章 设计概述

## 1.1 设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|---------|
| **手感还原** | 移动端技能释放手感接近王者荣耀 | 操作响应延迟 < 1帧(16ms) |
| **指示器直观** | 玩家按下技能后立刻看到范围预览 | 6种aimType都有对应的3D指示器 |
| **取消安全** | 玩家可以随时取消误操作的技能 | 手指划入取消区时有明确的红色变化反馈 |
| **零学习成本** | MOBA玩家无需教程即会操作 | 按下→拖拽→松手的统一范式 |
| **自适应布局** | 取消框/指示器在各分辨率下表现一致 | 750p/1170p/1640p 三种分辨率验证通过 |

## 1.2 设计原则

- **简洁性**: 战斗中操作必须1-2步完成——按下→松手，或按下→拖拽→松手。绝不引入额外确认步骤。
- **一致性**: 所有方向拖拽型技能(line/rect/sector)共用同一套操作范式；所有指示器都在技能按下时出现、松手时消失；取消框的位置和交互方式全局统一。
- **反馈性**: 按下有按钮缩放反馈(0.9x)；拖拽有指示器实时跟随反馈；进入取消区有颜色变红反馈；释放有技能施放反馈。每一步操作都有视觉确认。
- **容错性**: 取消区域判定半径 × 1.2 容错系数；智能释放兜底（快速点按不瞄准也能释放）。

## 1.3 体验愿景

> 玩家正在团战中，低血量的敌方射手在远处走位。玩家按下 Lux 的 Q 技能按钮——瞬间，角色脚下浮现一条绿色的光线指示器，右上角出现一个半透明的 X 取消框。
>
> 手指从按钮出发向左上方拖拽，绿色光线跟随手指方向旋转，精准指向那个残血射手。松手——光之束缚飞出！
>
> 如果拖着拖着发现方向不对？手指划向右上角的 X，指示器和取消框一起变红——"我要取消"。松手，技能取消，安全无误。
>
> 团战太激烈没时间瞄准？直接快速点按 Q——系统自动检测最近的敌人，光之束缚自动飞向那个方向。一切都在瞬间完成，战斗节奏零打断。

## 2.3 指示器系统(ViewportFrame层)

> 所有指示器使用独立的 ScreenGui → ViewportFrame → 3D Part 渲染，与PC端架构一致。

### ViewportFrame层级

```
PlayerGui
  └─ ScreenGui "IndicatorGui" (DisplayOrder=5, IgnoreGuiInset=true)
       └─ ViewportFrame "IndicatorViewport" (Size=1,0,1,0 全屏)
            ├─ Camera (与主相机同步, RenderStepped)
            └─ [动态创建的指示器Part]
                 ├─ line/rect: FillPart + LeftBorder + RightBorder + ArrowHead + OriginCircle
                 ├─ circle_drop: FillCircle + EdgeRing + [射程环在角色脚下]
                 ├─ sector: 多个WedgePart拼接扇形 + OriginCircle
                 └─ self_circle: FillCircle + EdgeRing
```

### 2.3.1 line 线形指示器布局

```
俯视图 (从上往下看):

     ┌──────────────────────────▷  箭头(ArrowHead)

```
俯视图:

## 2.4 技能按钮触控扩展

### 现有 vs 新增

| 对比项 | 现有实现 | 新增需求 |
|--------|---------|---------|
| 触控入口 | InputBegan(Touch/MouseButton1) | 不变 |
| 瞄准方式 | 2D方向轮盘(按钮上的指示线) | **3D指示器(ViewportFrame)** + 2D方向轮盘(可选保留) |
| 释放方式 | 松手时根据轮盘方向释放 | 松手时根据**指示器方向/位置**释放 |
| 取消方式 | 拖回按钮中心(取消区=按钮30%) | **拖到右上角取消框** |
| 智能释放 | 无 | **快速点按(<200ms, <10px) 自动朝最近敌人** |
| 状态分支 | directional→轮盘 / 其他→点按 | **根据aimType分6种模式** |

### 技能按钮状态扩展

现有8种状态(Idle/Pressed/Aiming/Cooldown/Ready/NoMana/Disabled/Dead/Locked)中，`Aiming` 状态需要扩展：

| 子状态 | 适用aimType | 按钮外观 | 说明 |
|--------|-----------|---------|------|
| Aiming_Direction | line/rect/sector | 按钮保持按下缩放(0.9x) | 拖拽更新方向 |
| Aiming_Position | circle_drop | 按钮保持按下缩放(0.9x) | 拖拽更新落点 |
| Aiming_Cancel | 所有(在取消区时) | 按钮边框变红 | 手指在取消区域内 |

# 第三章 交互流程

## 3.1 主流程：方向拖拽型(line/rect/sector)

```
                                    ┌──────────────────────────────────────────┐
                                    │             ✨ 交互时间线                │
                                    └──────────────────────────────────────────┘

[IDLE]                                                                          [IDLE]
  │                                                                               ▲
  │ 按下技能按钮                                                                  │
  ▼                                                                               │
[PRESSED]──── CD/蓝不足? ──→ 按钮闪红0.15s → [IDLE]                              │
  │                                                                               │
  │ CD/蓝充足                                                                     │
  ▼                                                                               │
  ├── 快速点按(<200ms, <10px)? ──→ [智能释放] ─→ FireServer → [IDLE]             │
  │                                                                               │
  │ 超过阈值, 进入瞄准                                                            │
  ▼                                                                               │
[AIMING] ◄─────────────────────────────────────────────────┐                     │
  │  · 显示指示器(line/rect/sector) + 射程环 + 取消框      │                     │
  │  · 按钮保持缩放(0.9x)                                  │                     │
  │                                                         │                     │
  │ 手指拖拽 (InputChanged)                                 │                     │
  ▼                                                         │                     │
  ├── 手指在取消区域内? ──→ 指示器+取消框变红 [AIMING_CANCEL]                     │
  │                          │                              │                     │
  │                          │ 手指离开取消区域               │                     │
  │                          └──→ 恢复正常颜色 ─────────────┘                     │
  │                          │                                                    │
  │                          │ 松手(在取消区域)                                    │
  │                          └──→ [CANCEL] 清理指示器+取消框 ──────────────────────┘
  │                                                                               │
  │ 松手 (InputEnded, 不在取消区域)                                               │
  ▼                                                                               │
[RELEASE] ──→ 计算最终方向 → FireServer(skillId, {direction=dir}) ────────────────┘
               清理指示器+取消框
```

### 方向计算逻辑

手指拖拽时的方向转换：

```
1. 获取手指屏幕坐标 (touchPos: Vector2)
2. 获取技能按钮中心坐标 (btnCenter: Vector2)
3. 计算屏幕方向: screenDir = (touchPos - btnCenter).Unit
4. 转换为世界方向: worldDir = screenToWorldDirection(screenDir)
   (复用现有摄像机投影逻辑, 投影到XZ平面)
5. 更新指示器旋转: indicator.CFrame = CFrame.new(charPos, charPos + worldDir)
```

### 落点位置计算逻辑

```
1. 获取手指屏幕偏移: delta = touchPos - touchStartPos (像素)
2. 将偏移映射到世界坐标:
   灵敏度系数 = Range / (屏幕短边 × 0.3)  ← 手指拖30%屏幕 = 满射程
   worldOffset = screenToWorldDirection(delta) × delta.Magnitude × 灵敏度系数
3. 目标位置 = charPos + worldOffset
4. 限制在射程内:
   if (目标位置 - charPos).Magnitude > Range then
     目标位置 = charPos + (目标位置 - charPos).Unit × Range
   end
5. 更新落点圆位置: dropCircle.CFrame = CFrame.new(目标位置.X, charY+0.05, 目标位置.Z)
```

## 3.3 主流程：点按即放型(self_circle)

```
[IDLE]
  │
  │ 按下技能按钮
  ▼
[PRESSED]──── CD/蓝不足? ──→ 按钮闪红 → [IDLE]
  │
  │ CD/蓝充足
  ▼
[INSTANT_CAST]
  · 短暂显示self_circle指示器(0.3s, Tween淡出)
  · 立即 FireServer(skillId, {direction=角色面朝方向})
  · ❌ 不显示取消框 (无瞄准阶段)
  │
  ▼
[IDLE]
```

> 💡 **设计理由**: self_circle 技能(如后羿Q多重箭矢、廉颇W熔岩重击)是即时自我buff/AOE，不需要瞄准，点按即放最符合操作习惯。显示0.3s的范围指示器只是为了给玩家"我影响了这个范围"的视觉反馈。

## 3.4 智能释放流程

```
[按下技能按钮]
  │
  │ 判定: 停留时间 < 200ms 且 手指移动距离 < 10px
  │
  ├── 是 → [智能释放]
  │         │
  │         │ 调用 getNearestEnemy(character, Range × 1.5)
  │         │
  │         ├── 找到敌人:
  │         │    ├── line/rect/sector: direction = (enemy.Position - char.Position).Unit
  │         │    ├── circle_drop: position = enemy.Position (限制在Range内)
  │         │    └── FireServer(skillId, params)
  │         │
  │         └── 未找到敌人:
  │              ├── line/rect/sector: direction = char.CFrame.LookVector
  │              ├── circle_drop: position = char.Position + LookVector × Range × 0.8
  │              └── FireServer(skillId, params)
  │
  └── 否 → 进入正常瞄准流程 (AIMING/TARGETING)
```

> 💡 **检测范围 = Range × 1.5**: 略大于技能射程，给智能释放更好的辅助瞄准范围。即使敌人在射程边缘外一点，也能自动瞄准——方向是对的，即使射程不够也不会让玩家困惑。

## 3.5 异常流程

| 异常情况 | 触发条件 | 处理方式 | 用户反馈 |
|----------|---------|---------|---------|
| CD中按下技能 | 按钮状态=Cooldown | 不进入瞄准，不显示指示器 | 按钮闪红 0.15s |
| 蓝量不足 | 当前蓝量 < 技能消耗 | 不进入瞄准，不显示指示器 | 按钮闪红 0.15s + 文字提示"蓝量不足" |
| 角色死亡 | 死亡事件触发 | 立即清理所有指示器+取消框 | 技能按钮进入Dead状态(全灰) |
| 被控制(眩晕/击飞) | CC状态触发 | 立即取消当前瞄准，清理指示器 | 按钮暂时Disabled |
| 多指同时按 | 第二根手指按另一技能 | 忽略第二根手指，只响应第一个 | 第二个按钮无反应 |
| AIMING中角色被击杀 | 死亡事件 | 强制取消，清理所有UI | 指示器消失+按钮灰化 |
| 设备模拟器鼠标操作 | Studio测试 | MouseButton1 视为 Touch | 鼠标拖拽 = 手指拖拽 |

## 4.3 触控手势规范

### 手势映射

| 手势 | 判定条件 | 对应操作 |
|------|---------|---------|
| 快速点按(Tap) | 停留 < 200ms 且 移动 < 10px | 智能释放 |
| 按住拖拽(Drag) | 停留 ≥ 200ms 或 移动 ≥ 10px | 进入瞄准模式(AIMING/TARGETING) |
| 拖到取消区(Cancel Drag) | 手指当前位置与取消框中心距离 < 取消框半径 × 1.2 | 准备取消(变红) |
| 松手(Release) | InputEnded | 释放技能 或 取消技能(在取消区) |

### 触控判定细节

| 参数 | 值 | 单位 | 说明 |
|------|-----|------|------|
| QUICK_TAP_THRESHOLD | 200 | ms | 快速点按最大时长 |
| QUICK_TAP_DISTANCE | 10 | px | 快速点按最大移动距离 |
| CANCEL_HIT_RADIUS_MULT | 1.2 | 倍数 | 取消判定容错系数(比视觉范围大20%) |
| DRAG_UPDATE_RATE | 每帧 | — | RenderStepped 更新指示器位置 |

### 多指触控防冲突

- 每次只允许一个技能按钮处于 AIMING/TARGETING 状态
- 全局锁: `isAiming = true` 时，其他技能按钮的 InputBegan 被忽略
- 松手/取消后才解锁: `isAiming = false`
- 摇杆和技能瞄准互不干扰（不同的 InputObject，手指ID不同）

## 4.4 跨设备适配

### 触屏设备(手机/平板)

| 适配项 | 方案 | 说明 |
|--------|------|------|
| 取消框位置 | Scale定位(0.85, 0.15) | 各分辨率下都在右上角 |
| 取消框大小 | 0.15×0.15 RelativeYY | 以屏高为基准，小屏不会太小 |
| 最小触摸目标 | MinSize 44×44 | 符合Apple HIG |
| 安全区 | CoreUISafeInsets | 取消框不被刘海/Roblox顶栏遮挡 |
| 方向灵敏度 | 基于按钮中心偏移 | 小屏/大屏手指拖拽距离自然适配 |
