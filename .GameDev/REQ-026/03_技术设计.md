## 1.2 发现的关键问题

### 🔴 Bug: 移动端→服务端参数类型不匹配

**现状分析**:
- `MobileInputManager.onSkillCast()` 调用 `CastSkillEvent:FireServer(skillId, direction)` ，其中 `skillId` 是 **number 类型**
- `PlayerSkillManager.server.lua` 的处理器期望 `function(player, key, targetPos)` ，其中 `key` 必须是 **string 类型** (`typeof(key) ~= "string"` 则 return)
- **结果**: 移动端技能释放请求被服务端静默丢弃

**修复方案**: 
- MobileInputManager 和 UI_SkillButtons 的回调链需要传递 `slotKey`(string, 如"Q"/"W"/"R") 而非 `skillId`(number)
- UI_SkillButtons 的 `onButtonTouchEnded` 已经有 `slotKey` 信息，只需确保正确传递

**优先级**: P0 — 在REQ-026中一并修复

## 2.3 数据流

### 方向拖拽型释放流程

```
1. 手指按下技能按钮
   UI_SkillButtons.onButtonTouchBegan()
   → 检查CD/蓝量
   → 读取 skillConfig.aimType
   → aimType="line"|"rect"|"sector" → 通知 MobileInputManager 进入AIMING
   → MobileIndicatorManager.ShowIndicator(aimType, config)
   → MobileCancelZone.Show()

2. 手指拖拽
   UI_SkillButtons.onButtonTouchMoved()
   → 计算世界方向 worldDir = screenToWorldDirection(delta)
   → MobileIndicatorManager.UpdateDirection(worldDir)
   → MobileCancelZone.IsInCancelZone(touchPos)?
     → true: MobileIndicatorManager.SetCancelMode(true) + MobileCancelZone.SetActive(true)
     → false: 恢复正常颜色

3. 手指松开
   UI_SkillButtons.onButtonTouchEnded()
   → if 在取消区域: 取消(清理指示器+取消框)
   → else: 回调 MobileInputManager.onSkillCast(slotKey, {direction=worldDir})
   → MobileInputManager → CastSkillEvent:FireServer(slotKey, {direction=worldDir})
   → MobileIndicatorManager.HideIndicator()
   → MobileCancelZone.Hide()
```

### 智能释放流程

```
1. 手指按下技能按钮
   UI_SkillButtons.onButtonTouchBegan()
   → 记录 touchStartTime + touchStartPos

2. 手指快速松开 (<200ms, <10px移动)
   UI_SkillButtons.onButtonTouchEnded()
   → 判定为快速点按
   → 调用 getNearestEnemy(char, Range*1.5)
   → 计算方向/位置
   → 回调 MobileInputManager.onSkillCast(slotKey, params)
   → CastSkillEvent:FireServer(slotKey, params)
   → MobileIndicatorManager: 无需显示(太快了)
```

## 3.3 UI_SkillButtons 扩展回调

```lua
-- 现有回调(保持):
skillButtons.OnSkillCast(function(skillId, direction) end)  -- 技能释放
skillButtons.OnAttackPressed(function() end)                 -- 普攻

-- 扩展回调签名:
skillButtons.OnSkillCast(function(slotKey: string, params: table) end)
-- params: { direction: Vector3?, position: Vector3?, targetId: string? }
-- slotKey: "Q"|"W"|"R"|"D"|"F" (string, 非skillId)
```

## 3.4 CastSkillEvent 协议

```lua
-- 旧格式(PC端, 不变):
CastSkillEvent:FireServer(key: string, direction: Vector3)

-- 新格式(移动端):
CastSkillEvent:FireServer(key: string, params: table)
-- params = { direction = Vector3?, position = Vector3?, targetId = string? }

-- 服务端兼容逻辑:
local function handleCastSkill(player, key, paramsOrDirection)
    if typeof(key) ~= "string" then return end
    
    local direction, position
    if typeof(paramsOrDirection) == "Vector3" then
        -- 旧格式兼容(PC端)
        direction = paramsOrDirection
    elseif typeof(paramsOrDirection) == "table" then
        -- 新格式(移动端)
        direction = paramsOrDirection.direction
        position = paramsOrDirection.position
    end
    
    -- ... 后续技能执行逻辑
end
```
