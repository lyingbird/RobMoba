## 3. 失败用例详情

### ❌ BUG-001: MovementManager 键名大小写不匹配 (🔴 P0 阻塞)

| 属性 | 值 |
|------|-----|
| 关联验收标准 | AC-04-1 |
| 严重程度 | 🔴 P0 阻塞 — 核心功能完全不可用 |
| 错误类型 | 逻辑错误 — table key 大小写不匹配 |
| 发现位置 | `Client.client.lua` L162 ↔ `MobileInputManager.lua` L109/113/119/208 |

**错误描述:**

`Client.client.lua` 第162行传入:
```lua
movementManager = MovementManager,  -- 小写 m 键名
```

`MobileInputManager.lua` 第109行访问:
```lua
if not modules or not modules.MovementManager then return end  -- 大写 M 键名
```

Lua table 键名大小写敏感，`modules.MovementManager` 返回 `nil`，第109行的 guard clause 直接 return，导致**虚拟摇杆的所有移动输入被静默忽略**。

**影响范围:**
- 🔴 虚拟摇杆移动**完全失效**，角色永远无法通过摇杆移动
- 同时影响 L208 的 `SetEnabled(false)` 中的停止移动逻辑

**修复建议:**
在 `Client.client.lua` 第162行，将键名改为大写 M:
```lua
MovementManager = MovementManager,  -- 大写 M，与 MobileInputManager 访问一致
```
同时第163行 cameraManager 也应一致改为:
```lua
CameraManager = CameraManager,      -- 大写 C，保持命名一致性
```

### ❌ BUG-002: CameraManager 未声明 local 变量 (🟡 P1 严重)

| 属性 | 值 |
|------|-----|
| 关联验收标准 | AC-05-2 |
| 严重程度 | 🟡 P1 严重 — 违反编码规范，潜在跨模块污染 |
| 错误类型 | 编码规范 — 隐式全局变量 |
| 发现位置 | `CameraManager.lua` L67/69/81/88/99 |

**错误描述:**

`CameraManager.lua` 使用 `mobileMode`（L67/81/99）和 `SMOOTH_FACTOR`（L69/88）两个变量，但**均未在文件顶部声明为 `local`**。

当前模块顶部声明（L14-17）:
```lua
local targetCharacter = nil
local targetRootPart = nil
local updateConnection = nil
local isPaused = false
-- 缺少: local mobileMode = false
-- 缺少: local SMOOTH_FACTOR = 0.15
```

**影响范围:**
- 功能上可工作（赋值时自动创建全局变量）
- 违反 Luau/Selene 编码规范（Selene 会报 `global_usage` 警告）
- 潜在跨模块污染：如果其他脚本也使用 `mobileMode` 全局变量名，会互相覆盖
- 全局变量查找性能略差于 local

**修复建议:**
在 `CameraManager.lua` 第17行（`local isPaused = false`）之后添加:
```lua
local mobileMode = false
local SMOOTH_FACTOR = 0.15
```

### ❌ BUG-003: 3个技能缺少 aimType 字段 (🟡 P1 严重)

| 属性 | 值 |
|------|-----|
| 关联验收标准 | AC-02-4 |
| 严重程度 | 🟡 P1 严重 — 非指向性技能交互方式错误 |
| 错误类型 | 配置遗漏 — 缺少必要字段 |
| 发现位置 | `HouYi_Skills.lua` L7(1009)/L27(1010), `LianPo_Skills.lua` L101(10520) |

**错误描述:**

策划案2.3节定义了5种 aimType（directional/area/self/channel/none），未设置 aimType 的技能默认为 `directional`（显示方向轮盘）。以下3个技能的 CastRule 决定了它们不应是 directional:

| 技能 | 技能ID | CastRule | 当前aimType | 应该设置的aimType | 问题 |
|------|--------|----------|-------------|------------------|------|
| HouYi Q (多重箭矢) | 1009 | Instant | ❌ 缺失(默认directional) | `"self"` | 自我增益技能显示方向轮盘，应点按即释放 |
| HouYi W (日之塔) | 1010 | Position | ❌ 缺失(默认directional) | `"area"` | 范围技能显示方向轮盘而非区域瞄准 |
| LianPo W (熔岩重击) | 10520 | Instant | ❌ 缺失(默认directional) | `"self"` | 自身护盾+AOE技能显示方向轮盘，应点按即释放 |

**对比: 已正确设置 aimType 的技能:**

| 技能 | 技能ID | aimType | 状态 |
|------|--------|---------|------|
| Angela R (炽热光辉) | 1008 | `"channel"` | ✅ 正确 |
| Lux E (光芒奇点) | 1004 | `"area"` | ✅ 正确 |
| HouYi R (烈日裁决) | 1011 | `"directional"` | ✅ 正确 |
| LianPo R (天崩地裂) | 10530 | `"area"` | ✅ 正确 |

**修复建议:**
- `HouYi_Skills.lua` 技能 1009: 在 `CastRule = "Instant",` 后添加 `aimType = "self",`
- `HouYi_Skills.lua` 技能 1010: 在 `CastRule = "Position",` 后添加 `aimType = "area",`
- `LianPo_Skills.lua` 技能 10520: 在 `CastRule = "Instant",` 后添加 `aimType = "self",`
