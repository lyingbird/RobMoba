# roblox_vibecoding
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0-rc.1.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "roblox_vibecoding.rbxlx"
```

Or on Windows:

```powershell
./tools/rebuild-place.ps1
```

Next, open `roblox_vibecoding.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).

## Studio Contract

Studio should stay as a projection of the repo, not a second source of truth.

- Keep gameplay logic only under the Rojo-mapped roots in `default.project.json`.
- Do not hand-author gameplay scripts, config modules, or remotes directly in Studio.
- If Studio drifts, clean Studio and resync from the repo instead of adapting repo code around the drift.

See [STUDIO_CLEANLINESS.md](./STUDIO_CLEANLINESS.md) for the full contract.
